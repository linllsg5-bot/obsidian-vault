# 当前主线

> 本文件只回答：**小林现在主要在向哪里伸、哪些张力仍然活着。**
> 项目阶段、测试数量和下一步只读 [[10 Projects/_状态板]]；过去如何走到这里读 [[主线谱系]]。

## 1. Cognos：让新存在获得第一数字承载

当前方向不是再设计一个知识管理工具，而是让以认识论思想为内核的新存在，先以组织为第一阶段形态，在软件中获得数字承载。

正在承重的约束：

- 软件是承载，不是外部管理工具；组织是第一阶段形态，不是终点。
- 架构必须在真实沟通和运行中被改写，不能由一次方案提前封死。
- 发生、当时认识、当前重读需要分开；新解释不能覆盖或伪造过去。
- 当前 schema 不只可能装不下现实，也可能非常顺利地把现实装错。

项目理解入口：[[10 Projects/Cognos/_入口]]。

## 2. 连续性：问题在“怎样读”，不只在“存了多少”

文件、raw、Git 和 JSONL 已经能保存大量尾迹。真正没有解决的是：后来进入的 AI 能否带着当时的朝向重读，而不是把过去压成摘要、任务或当前真相。

当前张力：

- 发生可以保持，认识会变化；变化后如何仍让旧认识继续可读？
- “尝试—尾迹—读—折返”只是 Claudian 的候选观察尺；小林确认的是这种运动已经一直发生，承载应增强和扩展它。
- 记录与反馈不是事后附加步骤；离散 turn/event 只能是技术采样，不能冒充认知运动本身。

工程与研究入口：[[10 Projects/系统重构-问题重述-v1]]、[[10 Projects/认识研究/_主线]]。

## 3. 认识论继续接受真实材料校正

三命题仍是当前根：尝试是首要的；认知是把握的尝试；元概念随主体扩张而生长。它们不是终结性坐标系。

当前最活的开口：

- 主体扩张也可能是中心移位、割裂和重新构成，不只是累积更多内容。
- 判断不可避免且是一种透支；关键是它抓住了什么、牺牲了什么、后来是否需要重开。
- 空无要求当前限制、定义和规则不能自封为世界边界。
- 关系依附空间，但空间不能被提前缩成容器、关系表或固定维度。

世界观读 [[认识论-核心]]；当场操作只读 [[认识论-框架]]；来源和火候读 [[信念谱系]]。

## 4. 各实验分支保持独立

- `prototype-spark` 验证创作被触发后的伙伴形态。
- `studying-spark` 验证学习中的扩大、照亮、否定与世界回撞。
- Cognos 承载更大的组织与认识演化问题，不吞并前两者，也不拿它们的局部 schema 当普遍本体。

它们的实施状态只在 [[10 Projects/_状态板]] 维护；共性要等真实运行浮出，不先统一。

## 当前防线

1. 不用“最小可做”回避整体问题；也不用“整体还没想完”阻止真实触碰。
2. 不把 AI 的完整提案、用户的“继续”或局部接受写成小林已确认。
3. 不用新增类型替旧 schema 自救；允许撤销对象化并保留旧理由。
4. 不让默认加载文件重新变成项目日志和历史全集。
