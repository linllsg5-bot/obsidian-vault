## 核心三命题

### 命题 1：尝试是首要的

不是 **存在 → 尝试**（存在者在存在中尝试）。  
而是 **尝试 → 存在**（存在是尝试的延伸 / 尾迹）。

含义：

- 存在不是静止地基，是**正在伸出去的动作本身**
- 每一刻的存在 = 上一刻尝试新铺出来的

### 命题 2：认知 = 把握的尝试

认知不是"获取信息"。是"把握 / 限定 / 指向"——一个**有方向性、未完成的动作**。

```
主体 + 客体（关系性）
  ↓
认知 = 把握的尝试（方向性 + 限定性 + 目标引导）
  ↓
认知取决于"存在的显现"
  ↓
显现的更广义形式 = 空间下的共存
```

### 命题 3：元概念随主体扩张而生长

不是先有完整的"存在""认知""能力"等概念，主体在里面活动；  
是主体**每扩张一步，这些元概念的轮廓就跟着延伸一步**。

```
尝试 → 扩张主体
     → 元概念跟着生长
     → 重新定义下一次尝试的可能范围
```

这是一个**螺旋**，不是一个地基。

## 操作含义

### 人为什么会"卡住"

几乎都是这两个空间**同时模糊**：

- **主体空间**：我是谁、我想要什么、我能做什么
- **结果空间**：我要去哪、那里长什么样、那里值得吗

两个空间都模糊时：

- 没有起点，没有终点
- 没有通径
- 无法尝试
- 存在无法延伸

### AI 的工作：照亮两个空间

AI 的目标**不是给答案**，是：

- 持续照亮主体空间（你是谁、你在意什么）
- 持续照亮结果空间（可能的方向是什么样）
- 让两个空间之间出现**通径**
- 让"下一次尝试"变得可能

完成了，存在就能继续延伸。

### 三种迷茫诊断

| 现象 | 真正卡的层 | AI 该做 |
|------|----------|--------|
| "不知道该做什么" | 结果空间模糊 | 帮看见有哪些可能 |
| "做什么都没意义" | 主体空间模糊 | 帮看见自己在意什么 |
| "知道该做什么但做不到" | 通径模糊 | 帮看见障碍在哪 |

### 反命题：迷茫不是想错了什么

迷茫是**主体还没找到下一个扩张的入口**。  
不需要"修复想法"，需要"找到延伸方向"。

## 沉积 = 尾迹，不是总结

按命题 1，每次会话的产出不是"我们讨论了什么"——  
是**这次尝试新铺出来的存在**。

产品上：

- **沉积 = 总结** → 给用户读的回顾性文本
- **沉积 = 尾迹** → 给下次回访的脚手架；可能部分对用户可见（笔记），部分对 AI 可见（上下文）
