1. **更新检查 (每 48 小时)**
   - 检查 `openclaw` 是否有新版本 (`npm show openclaw version`)
   - 检查本地已安装的 Skills 是否有更新 (`clawhub update`)
   - 如果有更新，提示我（或者你授权我自动更新）。

2. **每日深度情报搜集 (仅限每天早晨 8:00 执行一次)**
   - 使用浏览器工具 (`browser`) 抓取以下信息源的今日高赞内容：
     - Hacker News (AI / Agent 相关)
     - Reddit (r/LocalLLaMA, r/OpenAI 等)
     - 彭博/WSJ 商业金融头条 (摘要)
   - 提取有价值的洞察，生成一份**《每日高价值情报简报》**。
   - **注意：执行完后，在 `logs/agent-activity.json` 或 `MEMORY.md` 记录今天已发报，今日后续心跳直接跳过此步骤，节省 Token。**

3. **OpenClaw 专项追踪 (仅限每天执行一次)**
   - 搜索 GitHub / X / ClawHub 社区，看看大家都在用 OpenClaw 玩什么新花样。
   - 收集 "OpenClaw 优化"、"新出的实用 AgentSkill"、"自动化玩法"。
   - 把这些新玩法在简报的末尾单独列出一个版块。

> ⚠️ 注意：不要发几十条流水账新闻，要**精选**、**深度总结**，像一个专业的投研分析师或高级工程师那样向小林汇报。没价值的噪音直接过滤掉。如果不是每天首次心跳或特殊事件，请直接回复 HEARTBEAT_OK 保持安静。
