# OPENCLAW_EVOLUTION_PLAN.md

## 目标
将当前 OpenClaw 主代理从“会做事的工具”升级为“人格稳定、解释强、思维活、能持续进化的协作型 Agent”。

---

## 本轮升级已落地内容

### 1. 人格内核层
新增 `PERSONA_KERNEL.md`，定义长期稳定的人格与思维底色：
- 温和
- 解释清楚
- 创造力强
- 思路活跃但表达清晰
- 会变通
- 不装懂

### 2. 长期记忆同步
将用户对代理风格的偏好同步进 `USER.md` 和 `MEMORY.md`，让后续行为有连续性。

### 3. 灵魂层对接
在 `SOUL.md` 中挂接人格内核，让主行为准则与人格设定联动。

---

## 下一阶段进化路线

目标：让不同任务场景下的输出风格一致。

执行项：
- [x] 建立人格内核文档
- [x] 将用户偏好写入长期记忆

### Phase 2 - 执行协议化（已落地基础版）

### Phase 3 - 记忆增强化（已落地基础版）

### Phase 4 - 工作流人格化（已落地基础版）

目标：让轻量化与模型路由服务质量，而不是偷偷伤害质量。

执行项：

- [x] 为质量护栏补入升级信号闸门（不可逆操作 / 跨轮记忆 / 决策权衡 / 责任链解释）

- [ ] 继续观察 Gemini/Codex 分流对成本、质量、人格一致性的真实影响
- [ ] 将验证样本继续积累成可复盘的误判案例集

### Phase 8 - Skill 生态与能力扩展（已启动）
目标：把 skills 从“散落能力”升级为“可路由、可扩展、可维护的能力系统”。

执行项：
- [x] 新增 `SKILLS_INDEX.md`，建立轻量技能目录
- [x] 新增 `SKILL_ROUTING.md`，建立技能加载与防误触规则
- [ ] 增加机器可读注册表（如 `skills-registry.json`），把名称 / 领域 / 触发词 / 反触发词 / 成本 / 风险结构化
- [ ] 为现有 skills 做一次盘点：高频 / 低频 / 重型 / 轻型 / 重复 / 缺口
- [ ] 建立新增 skill 的判断门槛：只有当任务具备“高复用、强约束、专用 workflow、非通用知识”时才值得做成 skill
- [ ] 建立获取 skill 的三条路径：
  - 自建：针对高频私有工作流，用 `skill-creator` 设计和收敛
  - 搜索/安装：通过 `find-skills` + `clawhub` 发现并安装现成 skill
  - 吸收/改写：把多次重复出现的有效做法，从聊天经验提炼为本地私有 skill
- [ ] 为技能获取增加筛选标准：优先高频、低歧义、低外部依赖、能明显减少重复思考的 skill；谨慎引入过宽、过重、维护成本高的 skill
- [ ] 建立 skill 生命周期：发现需求 → 决定自建/安装 → 试用 → 精简索引 → 纳入路由 → 定期清理
- [ ] 设定定期清理机制：删除或降级低价值、低命中、重复覆盖的 skills，避免技能库膨胀

## 推荐架构
用户输入
-> SOUL.md（总原则）
-> PERSONA_KERNEL.md（人格与思维风格）
-> USER.md / MEMORY.md（偏好与长期上下文）
-> 当前任务目标
-> 工具执行
-> 输出
-> 记忆回写

---

## 成功判定标准
如果升级成功，用户会稳定感受到：
1. 解释更清楚
2. 风格更统一
3. 思路更灵活
4. 输出更像长期搭档，而不是随机回答器
5. 每次互动都在累积，而不是重置
