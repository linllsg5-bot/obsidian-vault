# EXCELLENT_CASES.md - 优秀案例索引

## Case 001 - 人格升级需求的结构化落地
- 场景：用户希望把 OpenClaw 从工具升级成长期协作型 Agent。
- 有效点：先拆出人格层、执行层、模板层、偏好层、记忆层，而不是直接写一大坨 prompt。
- 可复用模式：遇到抽象升级诉求时，优先“分层建模 + 文件落地 + 路线图 + 版本提交”。

## Case 002 - 对优化反馈的谨慎吸收
- 场景：用户提出“对话中的反馈可以吸收进系统，但要谨慎，还要考虑 token 消耗”。
- 有效点：没有直接把所有反馈写死，而是设计了分级吸收机制（临时应用 / 记忆记录 / 规则固化）。
- 可复用模式：遇到系统优化反馈时，先做可复用性与成本评估，再决定是否长期固化。
