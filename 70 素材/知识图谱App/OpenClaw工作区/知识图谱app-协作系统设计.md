## 🔄 系统架构

### Agent角色分工
```
用户请求 → [Commander] → [Lobster流水线] → [Coder] ↔ [Reviewer] → 最终输出
```

| Agent | 模型分配 | 核心职责 | 工具权限 | 成本/1M tokens |
|-------|----------|---------|----------|---------------|
| **Commander** | SiliconFlow DeepSeek-V3 | 需求分析、任务分发、结果聚合 | Lobster, llm-task, sessions_send, read | $0.28 |
| **Coder** | DeepSeek-V3 (主力) | 代码编写、实现、调试 | read, write, edit, bash, web_search | $0.42 |
| **Reviewer** | DeepSeek-V3 (轻量) | 代码审查、架构评估 | read, web_search (只读) | $0.28 |

### 数据流向
```
用户请求 → Commander → Lobster流水线 → Coder执行 → 写入共享日志 → Reviewer审查 → 返回结果
```

## 🛡️ 安全设计

### 1. 网络隔离
```json
"gateway": {
  "bind": "loopback",  // 仅本地访问
  "auth": {
    "mode": "token",   // 强token认证
    "token": "随机生成"
  }
}
```

### 2. 权限分离
- Commander: 仅通信和编排工具
- Coder: 读写执行权限
- Reviewer: 只读权限

### 3. 文件权限
```

├── workspace-commander/  # Commander私有
├── workspace-coder/      # Coder私有  
├── workspace-reviewer/   # Reviewer私有
├── shared/               # 共享目录，只追加
└── lobster-workflows/    # Lobster流水线
```
