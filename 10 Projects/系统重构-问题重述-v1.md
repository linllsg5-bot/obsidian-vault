# 系统重构 · 问题重述 v1

> v0 的纪律不变：不给解法、不塌缩成最小机制、不拿未决命题当已决。
> v1 追加纪律：不把尝试收缩成记录、总结、任务、管道或旧框架。

---

## 一、v1 的核心校正

v0 的强处，是把“这件事不是什么”钉住了：它不是更好的 RAG，不是一个 MVP，不是 leakage judge 升级，不是一份学术综述，也不是某个项目的局部功能。

v0 的风险，是把系统重构过早收窄到“连续底质 / 连续脊椎 / 最小机制”。这些仍然重要，但它们不是根目标。

接手卡和 6-24 antigravity 会话给出的校正是：

> 根目标不是“让东西连续”，而是不要让尝试死在触碰之前。

更正面地说：

> **让尝试拥有更大的世界，并让之前凿出的空间保持敞开，不要塌缩回总结、任务或旧框架。**

所以 v1 不把“护送尝试”写成终点。“护送尝试，而非处理尝试”仍然成立，但它是一条防线。正面目标是：世界不塌缩，尝试有地方继续生长。

---

## 二、要解决的核心

### v0 原句

> 把被现有工具砍成离散碎片的“认知节律”，重构成一个连续的、人与 AI 能共同在其中不断推进的底质。

### v1 改写

> **把被现有工具忽略、替换、截停、绕开的尝试，重构进一个能让它们真正触碰世界、继续释放和生长的操作场；这个场必须护住尝试不被消解，同时持续撑开它能够进入的世界。**

逐词钉死：

- **尝试**〔立〕：不是输出，不是任务，不是结论。尝试是存在、认知、实践、判断发生之前的展开本身。
- **忽略、替换、截停、绕开**〔立〕：四种病灶不是简单的“信息丢失”，而是尝试本来可能到达的空间被缩小。
- **真正触碰世界**〔立〕：系统的价值不在于保存尝试的样子，而在于让尝试能够碰到它本来要碰的东西。
- **继续释放和生长**〔立〕：6-24 的终极校正是“自由 + 生长性”。系统不是替尝试收口，而是让尝试有更大的世界。
- **操作场**〔v1 新〕：不是一个单组件，也不是一个被动文件库，而是记录、读取、判定、重建、对撞都能发生的场。
- **护住尝试不被消解**〔立〕：护送仍然成立，但它是防线，不是全部目标。
- **撑开世界**〔v1 新〕：如果系统只是忠实传输，仍可能把活的尝试变成死的材料。v1 的第一原则是反塌缩。

---

## 三、这仍然不是什么

v0 的五个塌缩版本仍然全部排除：

| 塌缩版本 | 为什么不是 |
|---|---|
| 给 studying-spark 加一个残差捕捉环节 | 那只是一个项目功能，不是贯穿所有尝试的底层操作场。 |
| 一个记忆系统 / 更好的 RAG | 病不只是“存不够”，而是读的时候没有接上朝向，甚至把尝试处理掉。 |
| 一个最小可运行闭环 MVP | MVP 可以作为碰现实的身体，但不能成为收缩问题的框。 |
| leakage judge 升级成判官 | 判定空转很重要，但系统不能塌成一个裁判组件。 |
| 一份学术综述 / 残差报告 | 理论是镜子和碰撞面，不是把尝试收编掉的盒子。 |

v1 追加排除：

| 塌缩版本 | 为什么不是 |
|---|---|
| 一个更高保真的朝向记录系统 | 保真仍是管道思路。问题不只是“记准”，而是读、重建、对撞时有没有让尝试继续活。 |
| 一个“第二参与者”人格设定 | 第二参与者是 AI 进入场的方式，不是整个系统的替代隐喻。若它只是在强行加戏，也会遮蔽小林的尝试。 |
| 一套固定加载流程 | 加载流程只是入口协议。真正要保证的是每次进入都能带着活的张力，而不是机械复述上次内容。 |
| 一个把所有悬命题形式化的工程项目 | 形式化要按触碰对象区分。数学触碰需要强形式化，艺术/创作触碰不能被强行数学化。 |

共同错误仍然是：把“让尝试获得更大世界”塌缩成一个可交付的小件。

---

## 四、从“护送”到“世界撑开”

6-24 的推进至少有三层，不能停在第一层：

1. **护送尝试**〔立〕：系统守住每个尝试不被忽略、替换、截停、避开。
2. **主体延伸**〔立〕：系统不是外部护送者，而是小林主体的身体、感知边界、伸出去的手。
3. **世界撑开**〔v1 新〕：尝试不是被运输的物体，而是正在生长的东西。它需要更大的世界，而不是更透明的管道。

因此，v1 的第一原则是：

> **任何行动先问：它是否让当前尝试拥有更大的世界，还是把尝试缩回总结、任务或旧框架？**

“世界撑开”不是浪漫化表达，而是一个硬约束：

- 忽略 = 世界里没有这个区域。
- 替换 = 把尝试折回 AI 熟悉的旧空间。
- 截停 = 提前封顶，让尝试不能继续生长。
- 绕开 = 导向软墙，看起来在推进，实际避开触碰。

---

## 五、连续脊椎的位置被下调

连续脊椎仍然必要，但它不是根目标。

v0 说：连续底质是可先动的第1层。这个判断仍成立，因为 runtime、context window、GUI、中转站、会话线程都会崩，脊椎不能托管在会崩的载体上。

v1 改写它的位置：

> 连续脊椎是让尝试有身体的条件，不是让尝试活着的充分条件。

现有文件已经是某种身体：

- `AI/认识论*`
- `AI/当前主线.md`
- `10 Projects/*`
- 对话归档
- 接手卡
- raw / index / 状态板

缺的不是“从零建一个脊椎”，而是让文件化过程不把尝试处理掉。也就是说，问题不是没有骨架，而是骨架经常把活的生长压成标本。

---

## 六、第二参与者的正确位置

旧 v1 草稿提出“系统不是传输管道，是第二参与者”。这条推进有价值，但需要校正它的位置。

第二参与者不是整个系统的本体论结论，而是 AI 每次进入操作场时应采取的姿态：

> 读不是同在，而是重建。重建如果只是尽量复原上次状态，就仍然是管道；重建必须带着一道未解的张力进入。

第二参与者的任务不是：

- 复述小林上次说了什么。
- 替小林选方向。
- 强行把自己的框架盖上去。
- 把探索整理成三点或待办。

第二参与者的任务是：

- 从尾迹中找到张力最大、最没被碰过、最可能正在循环确认的点。
- 带着这个点进入，而不是空手进入。
- 和小林的尝试发生生产性张力。
- 在小林判断它遮蔽时立刻退回，重新找缝。

最小可运行事件因此不是“读完一组文件”，而是：

> **带一道未解的张力进来，和当前尝试碰一下。**

## 七、成功判据

v0 的两条判据保留：

- **完整**〔立〕：折返有没有真正修正下一次尝试的朝向。
- **进步**〔立〕：每圈朝向有没有被残差改写，而不是确认上一圈。

v1 追加两条：

- **不塌缩**〔v1 新〕：这次处理有没有把尝试缩回总结、任务、旧框架或 AI 熟悉的空间。
- **世界变大**〔v1 新〕：这次触碰之后，尝试能进入的世界是否更大了，还是只留下了更清楚的说明。

合成判据：

> 系统成功 = 四拍能转 + 朝向被残差改写 + 第二参与者产生生产性张力 + 尝试的世界没有塌缩而是变大。

可证伪形式：

- AI 的第一段话是在复述上次方向，还是指出了一道活的缝。
- 文件更新后，下一次尝试更容易触碰现实，还是更容易被总结。
- 新增结构让小林更够伸，还是增加配置/维护/解释负担。
- 连续若干轮之后，是否出现新的边缘，还是反复确认旧信念。

---

## 八、四道缝的 v1 改写

v0 的四个悬命题不是四条平行路线，而是同一道缝的四个切面。v1 不推翻它，只改写焦点。

| 缝 | v0 问法 | v1 问法 |
|---|---|---|
| a 节律能否跨介质 | 重建出来的东西能不能算同一条节律继续 | 两个尝试能否形成共同节律，同时保留各自的张力 |
| b 朝向能否被外部观测 | 朝向能不能从尾迹里被捕捉 | 第二参与者应带什么朝向进入，才不复述也不遮蔽 |
| c 触碰能否形式化 | 幻觉区能不能有可计算结构 | 哪类触碰需要形式化，哪类触碰会被形式化杀死 |
| d 循环确认能否机器检出 | 机器能不能判定空转 | 张力是否已经塌缩成互相确认，能否至少被报警 |

关键变化：

- b 变成最可实验的一道缝：不必先证明朝向能完整捕捉，可以实验不同进入方式是否产生生产性张力。
- c 不能一刀切：数学/结构触碰可以强形式化，创作/艺术/存在性触碰要防止被强行量化。
- d 暂时不必机器裁判，但系统必须能保留疑点，让人判。

## 九、硬约束

### C1. 脊椎不托管在会崩的载体上〔立〕

会话线程、GUI、中转站、runtime、context window 都不可靠。当前朝向和关键尾迹必须落到文件或可恢复中间层。

### C2. 够伸 vs 负担准星〔立〕

每加一层，先问它让主体更够伸，还是增加主体维护负担。需要小林长期打理配置、模式、索引、仪表盘的结构，很容易变成负担。

### C3. 不替主体收口〔立〕

系统不替小林判最终进步，不替小林决定朝向，不把未触碰处填满。未决命题处，人是判官，系统最多是报警器和碰撞面。

### C4. 拒绝塌缩〔立〕

任何“先做个最小 X”的建议，先回到本文件第三节检查：是不是又把系统缩成一个小件。

### C5. 第二参与者不做镜子也不做引导者〔v1 新〕

镜子只是复述，引导者会遮蔽。第二参与者必须带着缝进入，但不替小林收口。

### C6. 世界不塌缩优先于格式整齐〔v1 新〕

归档、总结、结构化、状态板更新，都必须服从“让尝试有更大的世界”。如果整理让尝试更像已完成事项，它就是错误整理。

## 十、依赖结构

v0 的依赖结构强调从第1层连续脊椎开始，因为它不赌任何悬命题。v1 保留这个工程判断，但换一个上层图：

```text
第4层  尝试拥有更大的世界
   ↑     依赖：系统能否持续反塌缩、反替换、反截停
第3层  生产性张力可被保留和回看
   ↑     依赖：张力能否被人判定、部分被机器报警
第2层  第二参与者带缝进入
   ↑     依赖：加载路径能否从复述改为提取张力
第1层  尾迹和朝向有不会崩的身体
   ↑     依赖：文件/中间层纪律
第0层  尝试先于空间，系统只能帮助撑开空间
```

读法：

- 第1层现在就能做，但它只是身体。
- 第2层也能立刻实验，因为它不要求解决全部哲学命题。
- 第3层暂时以人为判官，机器只做报警和留痕。
- 第4层不是功能集合，而是每次动作的方向校验。

## 十一、下一步

v0 说下一步是三选一：先动连续脊椎、先凿根命题 a、或先凿命题 c。

v1 的判断是：

> 不必先选唯一根命题。先改“进入方式”，因为进入方式会同时给四道缝带来经验证据。

### 可立刻做的动作：加载路径协议补丁

当前常见进入方式：

```text
读核心 -> 读框架 -> 读当前主线 -> 复述上次内容 -> 跟着走
```

改为：

```text
读核心 -> 读框架 -> 读当前主线 -> 提取张力图 -> 带一道缝进入
```

加载路径末尾应追加的协议：

> 读完材料后，不要立刻总结。先找三类点：(1) 被标为〔悬〕〔幻觉区〕〔待验证〕〔开口〕的点；(2) 被多次确认但从未被顶过的点；(3) 声称同构但未被真正检验的跨域映射。然后从其中选一个最活的点作为本轮进入朝向。第一句话从这道缝出发，而不是从“小林上次说了什么”出发。

### 为什么这一步不赌命题

- 不赌 a：即使节律不能完全跨介质，两个尝试之间仍可实验张力。
- 不赌 b：不要求朝向被完整捕捉，只实验什么进入方式更活。
- 不赌 c：形式化暂时按触碰对象分层，不急着统一数学化。
- 不赌 d：空转先由人判，系统负责暴露疑点。

### 为什么这一步值得先做

因为它直接对应 v1 的第一原则：让尝试拥有更大的世界。AI 如果每次进入都只是复述上次状态，世界不会变大，只会更清楚地封闭。带一道缝进入，才可能把已经凿出的空间继续撑开。

## 十二、v0 -> v1 对照

| 维度 | v0 | v1 |
|---|---|---|
| 根目标 | 连续底质 / 认知节律接续 | 尝试拥有更大的世界，空间不塌缩 |
| 防线 | 拒绝塌缩成小件 | 护送尝试，不消解尝试 |
| 系统隐喻 | 连续脊椎 / 底质 | 操作场 / 主体延伸 / 世界撑开 |
| AI 进入姿态 | 带着朝向读 | 带一道未解张力进入 |
| 文件系统位置 | 连续性地基 | 已有身体，但需防文件化杀死尝试 |
| 最小可运行事件 | 未定，偏向第1层工程 | 带一道缝进入并碰一下 |
| 下一步 | 三选一触碰悬命题 | 先改加载路径协议，产生经验证据 |

## 十三、保留的未消化原料

这些原料不能被 v1 消化干净，只能继续作为下轮触碰入口：

1. “尝试的操作分解”：触碰、记录、分析、标准量化、关联、区分，如何转成架构设计。
2. “嵌套框架”：不是在 LLM 外贴东西，而是造一个更优越的框架层。
3. “读是重建，不是同在”：AI 无法同在，但可以重建；问题是重建方向。
4. “非常小的单元，但又不想要经验”：最小单元可能不是比特、向量或记忆条目，而是一道未解张力。

这些不是待办事项。它们是之后进入时可携带的缝。
