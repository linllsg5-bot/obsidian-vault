# Cognos 第一层：思想与原语

> `AI/认识论-*` 仍是跨 runtime 活源。本页只标出哪些内容目前足以约束 Cognos，哪些仍是候选或开口。

## 已承重

| 项 | 当前理解 | 主要来源 |
|---|---|---|
| 存在 | 不是空壳；以维持、展开和显现为基本朝向 | ex.1 追溯；[[AI/认识论-核心]] |
| 尝试 | 主体在其所处空间中的广义展开，不等于一个可调度任务 | ex.1、ex.3 校正 |
| 判断 | 尝试的一种特殊形态：浓缩、高效、一次性的透支，抓住核心也牺牲完整性 | ex.1—3 多次校正 |
| 可能/幻觉 | 主体在空间中面对尚未实际落地的方向；不能缩成候选答案列表 | ex.1、ex.3 |
| 现实 | 可能/幻觉的实际落地，包括成功、变形、阻碍、空响、超预期和主体不适 | ex.1、ex.2 |
| 空间与关系 | 对象在空间内共存；这种共存本身也是一种存在，称为关系。关系依附空间，存在还需要显现 | ex.3 明确校正 |
| 学习 | 认知，是尝试、主体及其对于存在的尝试的完整展开；不能缩成“写入一条记忆” | ex.3 明确确认 |
| 调度 | 主体与主体的联合，是主体的延伸和扩展，不只是任务分配 | ex.3 明确确认 |
| 空无 | 保留未透支可能性的建构态度，不是工程字段 | ex.1、ex.2 |

## 阶段性可用，但不要冻结

| 项 | 可用理解 | 保留的开口 |
|---|---|---|
| 主体 | 有一定独立性、可被区分，并具有展开性；是否被视为主体有门槛 | 门槛怎样产生，非人/非 AI 主体怎样真实参与 |
| 最小单位 | 相对于空间、尺度和问题而变；关键是“什么在什么情况下不能被忽视，能决定或组成什么” | 不把主体、事件或关系提前立为全系统唯一原子 |
| 分层 | 第一层是思想/原则，第二层是其承载与一定实现，后续继续延伸 | 每层怎样生成、怎样反向校正，不先画成固定五层 |
| 残余 | 可用来指判断之后被跳过、仍能牵引后续的部分 | 是否是独立原语、怎样与未知/可能区分 |

## 仍然开放

- 存在、主体、对象、空间、结构、关系和尝试之间完整的生成关系。
- 空间和承载能否分离，以及不同承载怎样塑造空间性质。
- “未知”位于空间与尝试之间时，是否是可能的前形态。
- 世界本身怎样可靠地被认识；世界映射怎样走向世界生成。
- 局部形成足以行动的确定结构时，整体怎样仍保留空无与开放。
- 原语究竟是起点、支撑、方向、相对基元，还是会在后续展开中被重新生成。

## 使用边界

- 这里的表不是术语字典，不要求每段对话打标签。
- “已承重”表示足以约束当前设计，不表示已经完成哲学证明。
- 任何新实现都应链接回它实际依赖的条目，同时记录它把该条目解释成了什么。
