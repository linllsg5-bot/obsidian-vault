### 承重

- 九步来路：学习研究 → 认识论 → 认识拆分 → 存在 → 变化 → 主体视角 → 尝试 → 幻觉/可能 → 空间。
- “概念泛论”不是一次真实尝试；记录系统不能替主体制造已发生。
- 判断不可避免，问题不是简单延迟判断，而是看见它抓住什么、牺牲什么。
- 现实是实际落地，不只等于阻力。
- 架构选择本身也是判断：每次先选中心都会塑造问题和答案空间。
- 组织作为第一阶段形态的想法在末段浮出。

### 明确否决

- Prompt 结构就等于 AI 真正思考。
- 用“推迟判断”“现实厚度数值门控”解决透支。
- 把发生、细胞、展开体或某种世界观直接定为最终原子。
- 用“先做一个小东西”回避整体问题。

### 开口

- 整体如何保留空无与开放，局部又形成足够推进的确定结构。
- 世界本体论探索与架构尝试怎样互相校正。
- 原语的生成关系、空间与承载、世界映射与世界生成。

### 明确校正与确认

- 上下文必须分层，核心思想、大致过程和项目情况都需要，但不能机械拼文件。
- 判断是透支；尝试和可能都比任务/候选答案更广。
- 关系是对象在空间内的共存，这种共存本身也是存在；关系依附空间，显现情况有很多。
- 调度是主体联合与延伸；学习是认知和完整展开。
- 位置先不定死；非人/非 AI 主体是后续实现问题。
- 第一层是思想、原语、理想、原则；第二层是其承载与一定实现，并继续延伸。
- 最小单位不固定；主体门槛、相对尺度和“不能被忽视”比选唯一原子更关键。
- 架构设计要在沟通中发生；先做雏形，再把后续设计搬进去。

### 只获局部接受

- 最小沟通空间、动态右侧信息、项目显示开放问题/共识/未采纳意见等方向被评价为“还行/可以继续”。
- 三层上下文在最后被评价“还可以”。
- A/B 计划的其他部分多是“还好，可以继续”或未逐项评价，不等于整份确认。

### 仍未确认

- 固定数据模型、`subject_level`、技术栈、存储权威和具体阶段顺序。
- 关系怎样在工程上真正超出边表。
- 最终提交给 agent 的方案：ex.3 以“几次都没得到满意回复”和再次请求最终方案结束。

### 小林明确认领

- 主体扩展会带来边界、性质与架构设计扩展。
- schema 变化不能失忆、断裂或伪造旧 schema 从未存在。
- 空无为第一准则，不允许限制、定义、计划与规则绝对化；保留可能与空间也保留幻觉产生。

### GPT 候选

- `H` 与 `Mₜ(H)` 分离、schema 是判断/透支、稳定是结构可变但连续性不断。
- 当前结构装不下的发生先保存，后来重新解释但不回写过去。
- schema 也可能把材料顺利装成一个由旧切法制造的错误对象；发生锚点尽量稳定而跨时间对象身份保持可改认；四种连续性与空间作为历史场。
