# 第 2 波：外部谱系检索（第一批）

## 本批完成了什么

- 将外部评价拆成四组机制问题，而不是搜索一个“Cognos 有没有先例”的总问题。
- 用 Crossref 公共 API 核验第一批 DOI、题名、年份和出版类型；对一条 enactivism/即兴论文读取了 Crossref 摘要。
- 建立 11 张来源卡，区分书目核验、摘要核验和全文精读；本批没有把 E1/E2 伪装成 E3。
- 形成主张—血亲对照矩阵，明确共享问题域、局部机制相似和关键差异。

## 当前结论

四组主张都有成熟外部血亲：具身/生成认知、agent 与 coordination theory、provenance/event sourcing、research-through-design/double-loop learning/distributed cognition。但本批没有发现一个单一来源把四组机制合并成 Cognos 当前的综合结构。

这不是“没有先例”，更不是“全球首创”。它只说明：在第一批检索边界内，Cognos 的组合方式尚未被一个已核验来源直接覆盖；仍需按缺口做第二批精读和反例检索。

## 证据限制

- 多数来源目前只有 DOI 书目信息；没有全文精读，不做细粒度理论归属。
- Crossref 的“命中”受查询词、索引质量和限流影响；429 只表示本次接口限流，不表示文献不存在。
- 本批没有系统检索中文数据库、学位论文、非 DOI 会议资料和软件设计档案。
- 外部来源只能说明其自身提出过什么，不能反向证明小林已认领或 Cognos 已实现。

## 下一批入口

优先沿五个缺口继续：

1. active inference、commitment、decision 与不可逆性，检验“判断透支”；
2. joint action、role emergence、multi-agent learning，检验四机制是否超出协调理论；
3. temporal ontology、schema evolution、identity split/merge/retraction，检验“装错”与认识史；
4. reflective systems、organizational cybernetics、human-AI co-adaptation，检验互相改写；
5. relation/process/event ontology，检验“关系是空间内共存本身”的差异。
