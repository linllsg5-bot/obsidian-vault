# 第 2 波：外部谱系检索与阶段评价

## 当前阶段判断（2026-09-22，Codex）

**Cognos 目前有可追溯的项目主张、若干真实失败样本和运行记录，但尚无足够证据支持整体学术原创性、独立新机制或相对既有方法的稳定优势。已有局部先例也不足以把整个项目裁定为重复。**

这是研究者判断，不是小林认领的新定义，不要求将项目改为纯实验平台。ex.4 msg 151 的研究/创造同步、msg 143 的“做出来之后仍有什么问题”共同约束评价。本文只推进研究交付，未授权或执行产品代码改动。

### 现在可以下的判断

| 评价层 | 证据与判断 | 不能越过的边界 |
|---|---|---|
| 历史与解释的表示 | PROV 已有修订、责任归属及来源陈述自身的来源结构；“能保存解释的历史”不是已证实的独特机制 | 规范不自动保证认领准确、撤回有效或未来不再误认 |
| 反馈影响后续行动 | Reflexion 已用文字反思和跨次尝试的记忆影响行动；不能将这一宽泛机制单独算作创新 | 这不等于小林所说的完整展开，也不证明 Cognos 与它等效 |
| 主体联合 | 参与式意义生成已讨论互动自身的组织及其对个体的作用；外部理论不能统一缩成任务分配 | 软件身份独立不证明理论意义的自主性；尚无联合效果的受控证据 |
| 判断透支 | 完整保存文本包括直觉与方向倾斜，不只显式决定或符号压缩 | Whitehead 目前只是值得定向比较的候选，尚不足以排为“最强”；attention 类比不是同构证明 |
| 位置、轮转与语言 | ex.4 msg 170、177、182 增加了位置不平等、持续承载及语言中介的要求 | 不能用角色重分配论文的摘要断言已覆盖，也不能用未查清的差异反证独创 |
| 实际运行 | 既有核验记录了原话留存、来源地位在转述中被升级等现象 | 原话在当前 state 中存在，不等于当时网络送达或有效采用；模型更换使学习归因不成立 |

前三项外部判断基于本轮重新定向核查的一手材料：[PROV-DM §5.2.2、§5.4](https://www.w3.org/TR/prov-dm/)、[Reflexion §3](https://arxiv.org/html/2303.11366v4#S3)、[De Jaegher & Di Paolo 2007，pp.492–493](https://hannedejaegher.net/wp-content/uploads/2009/11/dejaegherdipaolo07participatorysensemaking.pdf)。都是局部阅读，不宣称全文精读或结果复现。具体映射及边界分别见 [[第2波-PROV表达边界复核-2026-09-22]]、[[第2波-反馈记忆机制对照-2026-09-22]]、[[第2波-主体联合与参与式意义生成-2026-09-22]]。运行结论只限 [[第2波-运行证据核验-2026-09-22]] 指定快照。

### “方向倾斜”与 attention：一个可明确限缩的对照

Vaswani 等原始论文 §3.2 将 attention 定义为由 query/key 兼容度产生权重、对 value 加权；§3.2.2 另列学习得到的线性投影。因此，单次计算的注意权重与学习参数不是同一对象。[Attention Is All You Need，§3.2](https://arxiv.org/html/1706.03762v7#S3.SS2)

本研究的推论：这为 ex.4 msg 185 的“分配/倾斜”提供局部技术参照，却不证明直觉等于 attention、注意权重等于判断，或能从自然语言回复反推出模型内部权重改变。未获取内部张量，不作机制诊断。此处排除了错误等同，并未完成判断透支的哲学评价。

### 综合评价不能再用的三种捷径

1. **没有一个单独来源讲完所有东西，所以组合是新的。** 这是无效推论。贡献可能位于组合的耦合机制，但必须说清组合怎样产生已有部分分别不提供的作用；也可能已有分散传统共同覆盖。当前没有完成这样的比较。
2. **保存、检索、对话往返都存在，所以认识/组织已经形成。** 表示能力、实际采用、跨情境效果、哲学解释是四种不同证据；前者不能代替后三者。
3. **试验未证实，所以项目只能暂停或退成研究工具。** 未证实意味着收紧主张，不自动否决创造。研究可指出实现后的残余失败；是否施工及如何施工另依用户范围，不在本文偷偷缩小项目目标。

### 已经显示出的价值与尚待证实的贡献

就现有材料，我认为最明确的价值是：Cognos 把“能装进结构但装错了”“AI 的推演变成用户已确认”“保存了原话但后续没有正确面对”作为需要由承载与真实运行共同回应的问题。ex.1 的误造 Attempt 和运行记录的来源升级使这些不只是抽象担忧。

这支持继续开发和研究的问题动机，**不证明独特性或已经解决问题**。候选贡献若要成立，应落在明确机制如何同时保留历史、允许重解释、接受用户纠正与现实反馈，并在组织使用中产生可辨认作用；不能只靠词语更宏大或文档更多。此段为 AI 综合，不是增加项目本体。

## 当前结论

四组主张都有成熟外部血亲：具身/生成认知、agent 与 coordination theory、provenance/event sourcing、research-through-design/double-loop learning/distributed cognition。但本批没有发现一个单一来源把四组机制合并成 Cognos 当前的综合结构。

第二批缺口检索进一步表明：Cognos 的“调度”与 shared/joint action 有更近的哲学血亲；schema 风险与 ontology evolution 的区分直接相邻；组织层可与 Viable System Model 对照。但这些仍是分支血亲，不能拼接成“已有理论已经完整提出 Cognos”。

这不是“没有先例”，更不是“全球首创”。它只说明：在第一批检索边界内，Cognos 的组合方式尚未被一个已核验来源直接覆盖；仍需按缺口做第二批精读和反例检索。

## 证据限制

- 多数来源目前只有 DOI 书目信息；没有全文精读，不做细粒度理论归属。
- Crossref 的“命中”受查询词、索引质量和限流影响；429 只表示本次接口限流，不表示文献不存在。
- 本批没有系统检索中文数据库、学位论文、非 DOI 会议资料和软件设计档案。
- 外部来源只能说明其自身提出过什么，不能反向证明小林已认领或 Cognos 已实现。

## 第二批精读结果

第二批已完成部分公开全文/摘要核验，新增独立档案见 [[第2波-第二批精读]]。其中：

- Whitehead 的 process philosophy 是“判断透支”目前最强的哲学血亲，但它是普遍过程本体论，不等于 Cognos 的运行主张。
- Coordination theory、joint action 和 dynamic role allocation 分别覆盖依赖管理、联合行动和位置重分配；没有单一谱系等于 Cognos 的调度定义。
- Ontology evolution 直接命中“结构变化不是数据库迁移”的问题；provenance 的全文则显示来源追踪有 why/where 的语义边界，不能自动升级为认识史。
- BioNLP 的实体—关系—事件表示支持工程展开，但不证明“关系是空间内共存”的本体承诺。
- Research-through-design 支持“做中认识”，但仍未覆盖持续运行的软件组织与认识论互改写。

第三批已补检索 shared intention/joint control/joint affordance、动态角色分配综述、VSM 经验检验、二阶控制论设计研究和人机社会技术共适应。结果显示：联合行动和二阶控制论分别更接近“主体联合”和“做中改写认识”，但仍未找到同时覆盖 Cognos 四机制、发生/解释分离和软件承载的单一来源。
