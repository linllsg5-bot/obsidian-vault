## 一、第一发生场真实使用

- 第一发生场已从单一 Codex runtime 扩展为 Codex / Gemini 可选 runtime，并开始真实沟通。
- Gemini 在复杂 Cognos 局面中快速生成“代谢器官”“统一中枢”等整体解释；小林明确顶回这些未确认结构，并要求 Gemini 把自身回答作为场内发生重新区分“事实 / 自己生成的理解结构”。
- 随后出现“伪造完整性”、疑惑、目的与空间等讨论，但这些仍属于现场材料和候选认识，不能直接升格为 Cognos 理论或 schema。

## 二、项目推进重新收束

小林随后明确指出：讨论已经离项目推进太远，需要回到项目计划和实际工程。

阶段判断转为：

- 第一发生场不再继续围绕单 runtime 体验打磨；
- 当前工程桥梁是 **第一组织切片**：从 `assistant slot + runtime switch` 推进到多个不互相替换、各自保持 runtime continuity 的 participant 在同一发生场共在；
- 第一版只要求 participant/runtime 分离、各自连续性、发生归属、显式让一个 participant 面对另一个 participant 的 occurrence；
- 不抢跑自动多 Agent orchestration、中央总控、固定 Role / Position、全局广播或自动对吐。

这一步只是从“发生场”走向“组织”的桥，不是 Cognos 的总方向本身。

## 三、小林对推进方式的关键校正：不能只有“下一刀”

小林明确反馈：上下文已经很长，项目又有大量文件与历史讨论；如果 AI 只给局部下一步，会让自己完全失去大方向感，甚至觉得 AI 在“降智”。

由此对项目管理方式作出重要修正：

```text
稳定的大地图
    ↓
当前战役
    ↓
局部探针 / 下一刀
```

“不要过度设计”不能被执行成“不要有大计划”。局部结构可以开放，但 AI 应持续维护：

- Cognos 到底在向哪里长；
- 现在有哪些同时活着的研究 / 工程地形；
- 当前工程位于哪片地形，正在从哪里走向哪里；
- 哪些远处地标仍然存在，即使当前路线改变。

因此 2026-08-16 新增 [[10 Projects/Cognos/大地图]]，作为慢变化的项目方向层；[[10 Projects/Cognos/实施计划]] / [[10 Projects/_状态板]] 负责当前战役；具体实现任务作为快变化局部层。

## 四、全局重读后的重要发现

为回应“小林担心 AI 漏掉长上下文和各文件”，当前 GPT 不再只凭上下文摘要，而开始跨文件重读当前活源、认识史、8/14 两个 GPT 分叉、系统重构、认识研究、conversation lineage 与第一发生场运行数据。

重读确认：

1. 8/13 项目文件明显落后于 8/14—15 的认识与工程现实；
2. 8/14 “语言 / 场 / 睡眠”分支后段已经推进到持续暴露、Reach、`NotRecognized ≠ NotEffective`、`WorldChange → EffectPropagation → World/PositionChange → SubjectReentry → View`、`ActiveCognition(S)=0` 但关系/处境仍可持续等候选方向；这些不只是遥远想象，但也尚未成为正式 schema；
3. `Persistent History ≠ Position ≠ Viewpoint` 仍应守住；P1 不能替 P2/P3 提前证明位置；
4. `AI/认识论-核心.md` 等所谓“核心”文件也可能保留旧的过强措辞，需要结合后来的信念谱系与 raw 重新审计，不能因为文件名是“核心”就把它当永久真理；
5. 当前真正存在的是一笔**文档同步债务**：认识发展速度已经超过项目活源同步速度。

## 五、当前大方向（本轮修正后的较稳定地图）

Cognos 不是一条线性 Phase，而至少同时包含六片互相作用的地形：

- 认识与生成；
- 世界与现实回撞；
- 发生 / 历史 / 认识史 / 连续性；
- 组织与多主体共在；
- 空间 / Position / Relation / Reach / View / Field；
- 持续世界 / runtime 身体 / 潜在耦合与重入。

当前工程仍然位于：

```text
第一发生场
→ 第一组织切片
→ 第一个真实组织闭环
```

更远地标包括：History 真正成为 Memory、Position/Relation/View 产生行为差异、模型不生成时世界仍持续变化、异构 runtime 身体、以及 Cognos 越来越多地在 Cognos 内建设自身。
