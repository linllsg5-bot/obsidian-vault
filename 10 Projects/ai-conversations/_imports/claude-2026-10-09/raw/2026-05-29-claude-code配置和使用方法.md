Claude Code的安装其实很简单，没有什么"ecc框架"——你可能是看到了某篇不太准确的介绍。核心依赖只有 **Node.js**，其他都是一条命令的事。

---

## 前置条件

**需要的东西：**
- Node.js v18 或更高版本（没有就先装这个）
- Claude Pro（$20/月）、Max、Teams、Enterprise 账号，或者 Anthropic Console 的 API Key
- 免费计划不包含 Claude Code

**检查 Node.js 是否已安装：**
```bash
node --version   # 需要 v18+
```

如果没有，推荐用 [nvm](https://github.com/nvm-sh/nvm) 安装 Node.js，避免权限问题。

---

## 安装（30秒）

```bash
npm install -g @anthropic-ai/claude-code@latest
```

验证安装：
```bash
claude --version
```

## 登录认证

```bash
claude auth login
```

或者直接设置环境变量 `ANTHROPIC_API_KEY`（适合用 API Key 的方式）。

## 两种使用方式

Claude Code 有两种形态：一是 Claude Desktop 应用里的 Code 标签页（图形界面），二是命令行 CLI 工具。

- **桌面应用**：2026年4月14日 Anthropic 发布了全新设计的 Claude Code 桌面应用，支持 macOS 和 Windows，从 claude.com/download 下载，登录后打开 Code 标签即可。注意 Linux 不支持桌面应用，只能用 CLI。

- **命令行**：进入你的项目目录，直接运行 `claude`，然后用自然语言描述你要做什么就行了。

方向是对的，流程感已经有了。但有一个地方有个关键认知需要纠正，这个很重要：

**工具不是模型执行的。**

模型做的事只有一件：输出文本。当它"调用工具"时，实际上是输出了一段结构化的文本，大概长这样：

```json
{
  "type": "tool_use",
  "name": "search_web",
  "input": {"query": "xxx"}
}
```

然后是**你的代码**（OpenClaw）读到这个输出，识别出这是个工具调用指令，去真正执行那个工具，拿到结果，再把结果塞回给模型继续对话。

所以整个循环是：
```
模型输出"我要调用工具X" → 你的代码执行X → 结果返回给模型 → 模型继续
```

模型全程在数据中心待着，什么都没动。动的是你这边的代码。

---

这个区别很关键，因为它决定了**Agent 的能力边界完全由你的代码决定**，而不是模型本身。

* 架构的重量不能转移给用户的感知
2. 不是用户在管理系统，是系统在跟踪用户在乎什么

* 用户在对话中的自然姿态（引用某句话继续写、展开某条材料）= 系统识别并悄悄记录的信号
* 不设显式的"保存/归档"动作
3. 沉积 = 保留对话原文，不是总结

* 用户做的、问的才是需要保留的
* 不需要刻意总结，只需要保留
* 沉积作为历史存在，Block 被重写后旧沉积不继承
4. 材料应尊重原样保留，不做"精炼"
