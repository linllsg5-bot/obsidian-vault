## AI

取决于你用的是哪个 AI 平台，方法不太一样：

**Claude.ai**
- 网页端：设置 → Privacy → Export Data，会导出所有对话的 JSON 文件
- 目前没有官方的一键导出单个对话为 Markdown 的功能

**ChatGPT**
- 设置 → Data controls → Export data，同样是 JSON 格式
- 浏览器插件 **ChatGPT Exporter** 可以导出单个对话为 Markdown / HTML / PDF

**通用浏览器插件方案**
- **MarkDownload**：把网页内容（包括对话页面）保存为 Markdown
- **SingleFile**：把整个页面保存为单个 HTML 文件，离线可读

**第三方工具**
- **Obsidian** + 相关插件：有人做了能把 ChatGPT/Claude 导出 JSON 导入 Obsidian 的脚本
- **chatgpt-to-markdown**（GitHub 上有几个同名项目）：专门处理 ChatGPT 的导出 JSON，转成可读的 Markdown

**Claude.ai 导出**

1. 点击左下角头像 → **Settings**
2. **Privacy** → **Export Data**
3. 会发一封邮件到你注册邮箱，下载压缩包
4. 里面是 JSON 格式，需要转换才好阅读

转换 JSON 可以用这个开源工具：**claude-export**（GitHub 搜索即可），能转成 Markdown。

---

**ChatGPT 导出**

官方同样有导出，但更推荐浏览器插件：

- **ChatGPT Exporter**（Chrome/Edge 插件）
  - 可以导出单个对话，格式支持 Markdown、HTML、PDF、JSON
  - 不用等邮件，即时导出
  - 在 Chrome 应用商店搜索 "ChatGPT Exporter" 即可

---

**如果你想统一管理两边的记录**

可以都导成 Markdown，丢进 **Obsidian** 或者任何支持 Markdown 的笔记软件（Notion、Typora 等），方便后续搜索和整理。
