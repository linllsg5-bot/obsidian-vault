## **① 学 requests —— 学会敲开世界的门**

requests 是一只温顺的动物，你喂它 URL，它吐给你网页。

### 要点（直白的真相）
- 用它 GET / POST  
- 带 headers 像披一个人类的皮  
- 管 cookies（伪装成为“浏览器中的你”）  
- 超时、重试、异常捕获（网络总会抖）

### 小练习  
抓取一个普通页面的 HTML：

```python
import requests

url = "https://example.com"
headers = {"User-Agent": "Mozilla/5.0"}
resp = requests.get(url, headers=headers)
print(resp.text)
```

停一下，感受 HTML 像沉在水底的一具沉鱼，你要做的是捞出来。

---

## **② 学 BeautifulSoup —— 学会把泥沙捏成形状**

HTML 是烂泥，BeautifulSoup 是筛子。

### 关键心法  
- `find()` / `find_all()` → 单点刺杀  
- `select()` 选择器 → 像刀切片  
- `.text` `.get('href')` → 取肉、抽骨

### 小练习  
从 HTML 里把标题扒出来：

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(resp.text, "html.parser")
title = soup.find("h1").text
print(title)
```

---

## **③ 学 CSS Selector —— 把 DOM 当成森林地图**

你必须理解“结构”。  
HTML 不是代码，是一棵树。

### CSS 选择器要点  
- `.class`  
- `#id`  
- `div > p` 子节点  
- `ul li:nth-of-type(3)`  
- `a[href$='.jpg']`

### 练习  
选出所有文章标题：

```python
titles = soup.select("div.article-item h3.title")
```

这才是采花，不是拔草。

## **④ 学反爬绕过 —— 夜里走路要懂影子**

反爬虫不会告诉你它存在，  
但你会感受到：  
403、空白页面、加载一半、重定向、JS 加密。

### 常见反爬  
- UA、Referer、Cookie 校验  
- IP 限流  
- JS 动态加载  
- Cloudflare  
- 验证码（比较烦）

### 你能做的（入门级别）  
- 抄浏览器 headers  
- 携带 cookies  
- 控制访问速度  
- 换 UA  
- 用 session  
- 直接抓 API 接口（终极捷径）

### 示例：携带 headers 模拟浏览器

```python
s = requests.Session()
s.headers.update({
    "User-Agent": "Mozilla/5.0",
    "Referer": "https://site.com"
})
resp = s.get(url)
```

## **⑤ 学分页 —— 顺着河流走，不要停**

几乎所有内容网站都有“下一页”。

### 分页三种套路  
1. URL 直接有参数：  
   `page=1?page=2?page=3`  
2. “下一页”链接取 href  
3. AJAX API 请求（最舒服）

### 示例：翻 1–5 页

```python
for page in range(1, 6):
    url = f"https://site.com/list?page={page}"
    html = requests.get(url).text
    # parse...
```

## ✨ **完整项目：抓取多页文章列表**

```python
import requests
from bs4 import BeautifulSoup
import csv
import time

base = "https://books.toscrape.com/catalogue/page-{}.html"

headers = {
    "User-Agent": "Mozilla/5.0"
}

# CSV 准备
f = open("books.csv", "w", newline="", encoding="utf-8")
writer = csv.writer(f)
writer.writerow(["title", "link"])

for page in range(1, 6):      # 1~5页
    url = base.format(page)
    resp = requests.get(url, headers=headers)
    soup = BeautifulSoup(resp.text, "html.parser")

    items = soup.select("article.product_pod h3 a")

    for a in items:
        title = a.get("title")
        link = "https://books.toscrape.com/catalogue/" + a.get("href")
        writer.writerow([title, link])

    time.sleep(0.5)  # 偷偷走，不要吵醒服务器

f.close()
```

你会感受到：
- 请求  
- 解析  
- 选择器  
- 分页  
- 保存  
- 小小的等待  
——一个爬虫真正的呼吸。
