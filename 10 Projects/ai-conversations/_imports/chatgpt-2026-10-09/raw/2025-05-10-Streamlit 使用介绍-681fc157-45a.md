## 概要  
执行命令 `streamlit run your_script.py` 会启动本地的 Streamlit 服务器，并自动在浏览器中打开一个新标签页来展示你的应用。citeturn0search0

## 命令拆解  
- **`streamlit`**：Streamlit 安装后自带的命令行工具，用于管理与运行 Streamlit 应用。citeturn0search3  
- **`run`**：子命令，告诉 Streamlit CLI 启动并运行指定的 Python 脚本作为应用入口。citeturn0search1  
- **`your_script.py`**：你的应用脚本文件路径，即入口文件（entrypoint）。在多页面应用中，它也可以作为页面路由器；单页应用则当作主页。citeturn0search1

## 执行后发生了什么  
1. **启动本地服务器**：在你的机器上启动一个 Streamlit 后端进程，监听默认端口（通常是 8501）。citeturn0search0  
2. **打开浏览器**：Streamlit CLI 会尝试在系统默认浏览器中打开一个新标签页，指向 `http://localhost:8501`，即你的应用界面。citeturn0search0  

## 进阶用法与提示  
### 传递脚本参数  
如果脚本需要接收命令行参数，可以在脚本名后直接添加；Streamlit 配置选项与脚本参数之间用 `--` 分隔。如：  
```bash
streamlit run your_script.py -- --mode production
```  
此时，`sys.argv[1:]` 会返回 `['--mode', 'production']`，而不会包含任何配置选项。citeturn0search1  

### 指定运行环境（以 Windows 为例）  
在 Windows 的命令提示符中，只要安装了 Streamlit，就能直接执行：  
```bash
streamlit run your_script.py
```  
无需考虑可执行文件路径，只要所在目录正确即可。citeturn0search7  

### 部署到服务器  
在云服务器或远程主机上，同样使用 `streamlit run your_script.py` 即可启动应用。然后通过服务器 IP 加上端口号（如 `http://<服务器IP>:8501`）进行访问。citeturn0search7

## 核心特性  

### 1. 简洁易用的 API  
Streamlit 将所有 UI 组件都暴露为 Python 函数，开发者只需按脚本式编程方式调用即可，不需要设置路由、编写前端代码或处理 HTTP 请求 citeturn0search0turn0search1。  

### 2. 拖拽式界面构建（可选）  
官方核心包并未内置可视化拖拽编辑器，但社区中已有组件如 `streamlit-elements`，可让你创建可拖拽、可调整大小的仪表盘布局，增强页面的自由排版能力 citeturn1search6。  

### 3. 多种数据格式支持  
内置对 Pandas、NumPy、Matplotlib、Altair、deck.gl 等常用数据与可视化库的兼容，你可以直接将 DataFrame、数组或图表对象传给 `st.dataframe()`、`st.line_chart()`、`st.map()` 等函数展示数据 citeturn0search2。  

### 4. 丰富的交互式组件  
Streamlit 提供多种交互式小部件，包括滑块（`st.slider()`）、按钮（`st.button()`）、复选框（`st.checkbox()`）、下拉框（`st.selectbox()`）、文本输入（`st.text_input()`）等，让用户能够动态控制应用状态 citeturn0search3。  

### 5. 多样的部署选项  
- **Streamlit Community Cloud**：免费托管公开应用，直接从 GitHub 部署。  
- **Snowflake & 企业方案**：通过 Snowflake 平台实现私有部署，也可选用 AWS SageMaker、Azure ML 等其他云服务 citeturn0search7turn0search0。  
- **本地与 Docker**：在本地或容器环境中运行，适合快速迭代和内部测试。
