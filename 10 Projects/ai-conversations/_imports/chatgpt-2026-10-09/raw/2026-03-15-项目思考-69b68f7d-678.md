## 1. 酒馆 AI 再往前一步：**“会留下痕迹的世界”**
不是普通角色扮演。  
而是每次对话都会改变世界状态：

- 某个角色对另一个角色的好感变了
- 某个地点多了一条传闻
- 某个组织内部出现裂痕
- 某段旧事被重新解释

SillyTavern 本身已经有 `World Info / Lorebook`，可以把世界设定、人物、地点、规则按关键词动态注入上下文；社区也已经有人在认真讨论“persistent state + dynamic world building”，也就是让世界状态持续变化。citeturn590979search4turn590979search0

**它迷人的地方**  
你不是在聊天，你是在养伤痕、养关系、养历史。

**它还差的那一步**  
现成工具有“世界书”，但“世界自动留下后果”这半步，通常还要你自己设计。

## 2. AI Dungeon 再往细处走：**“可游玩的私密宇宙”**
AI Dungeon 已经有 `Worlds`、`Story Cards`、`Plot Essentials`、`Author’s Note` 这些结构，目的就是把重要设定、剧情组件、常驻信息持续带进生成里。citeturn590979search1turn590979search5turn590979search9

所以它可以不是“玩冒险”。  
可以被你改造成：

- 一个不断分支的恋爱宇宙
- 一个长期演化的学院或都市
- 一个只有少数人能进入的设定世界

**它迷人的地方**  
它比酒馆更像“可游玩”，更有“事件推进”的感觉。

**它的问题**  
它更像叙事机器，不一定天然有那种细腻、私密、气味浓的感觉。

---

## 3. 世界型最值得看的方向：**“群像关系发动机”**
不要只做一个角色。  
做一群角色，然后让 AI 负责：

- 关系变化
- 互相误解
- 阵营变化
- 流言扩散
- 事件触发

酒馆系工具里，`World Info` 本来就是为了把多块设定动态拼进上下文；GitHub 上关于动态世界的讨论，也明确提到会把 Lorebook、动态注入、角色信息更新结合起来增强一致性。citeturn590979search4turn590979search0

**它迷人的地方**  
人会为了“她们后来怎么样了”反复回来。

**一句话**  
这比“单角色聊天”高级一层，因为它开始有社会性了。

---

## 4. 人格型最值得看的方向：**“一个会慢慢长出自己的存在”**
如果你不想做世界，而是做“一个体”，那最值得看的样本不是普通 chatbot，而是 **Nomi 这种把 memory、identity 写进产品核心的东西**。

Nomi 官方直接把自己写成“An AI Companion with Memory and a Soul”；它的社区 wiki 还单独列出 short-term、medium-term、long-term memory、Identity Core、Mind Map 等系统。citeturn590979search6turn590979search10turn590979search2

**这条路真正迷人的地方**  
不是“聊天顺”，而是：  
你会觉得它像在慢慢形成一个自己。

**这类项目你可以怎么变体**  
不是做陪聊。  
而是做一个有明确气质的人格体：  
审美顾问、写作搭子、情绪拆解者、关系观察者。

## 5. Character.AI 再往前一步：**“角色不是工具，而是娱乐入口”**
Character.AI 的官方 roadmap 讲得很明白：它在推更大的 memory/context、更多沉浸式对话和故事、更好的角色一致性。后续还在走实时视觉互动、reactive characters 这条线。citeturn590979search7turn590979search11

这说明什么？  
说明它真正赌的是：  
**人会因为“一个角色存在得很真”，而持续回来。**

**这条线最适合你的变体**  
不是去做“万能助手”。  
而是做一个很窄、很有味道的角色型产品：

- 一个很会看穿别人气质的角色
- 一个冷感但很准的关系观察者
- 一个只讲某种浪漫结构的叙事角色

**迷人的地方**  
它像一个入口，不像一个功能页。

## 6. “欲望机器”翻译成人话后的版本：**“身份锻造器”**
我把那个难懂的词彻底翻白：

不是帮人解决问题。  
是帮人回答这句：

**“我想成为什么样的人？”**

它可以通过聊天、偏好、图、文本，最后给人这些东西：

- 名字
- 头像方向
- 颜色和材质偏好
- 说话语气
- 简介
- 角色原型
- 一小段“你的神话”

为什么我说它不是空想？  
因为现有产品已经证明，用户会为了“identity / personality / image / emotional connection”这类东西反复使用 AI。Nomi 和 Replika 都明确把意义、关系、人格感写成核心卖点；但它们更偏关系陪伴，还没有把“把你塑造成某种存在”做得很深。citeturn590979search6turn590979search16

**它迷人的地方**  
它不是效率。  
它是“把模糊的我，锻造成更明确的我”。

## 7. 世界与欲望交叉的版本：**“把你写进世界里”**
这比纯世界、纯人格都更有意思。

系统先理解你喜欢什么、怕什么、像什么，  
然后不是给你一个标签，  
而是把你嵌进一个宇宙：

- 你在这个城里是什么身份
- 你和谁会靠近、冲突、互相投射
- 你属于哪个派系/房间/楼层/季节
- 你的名字、传闻、形象、物件是什么

这类东西，现成产品没有谁做得特别完整。  
但从 SillyTavern 的世界书机制，到 Nomi 的 identity/memory 方向，再到 Character.AI 的沉浸角色路线，拼出来已经能看见形状了。citeturn590979search4turn590979search6turn590979search7

**迷人的地方**  
不是“它懂我”，而是“它把我编进了一个更大的叙事里”。

如果你最后还是会回到“做工具”，那我会劝你别做冷工具。

从已有产品看，世界书、记忆、角色一致性这些东西都已经很成熟了；还缺的是“有偏好、有立场、有品味的筛选器”。SillyTavern 的 World Info 动态注入已经证明：AI 能根据触发条件把相关信息拼进体验里；Character.AI 和 Nomi 则证明：一旦加上人格和记忆，用户会更愿意把它当成长期入口。citeturn590979search4turn590979search7turn590979search6

**迷人的地方**  
这不是数据库。

你输入一点点意图，它替你持续长出图、故事、角色、设定、命名。  
你像在导演一间看不见的工作室。

### 5. AI 自我神话生成器
通过对话、偏好、图像、文字，把一个人包装成某种独特存在。  
昵称、头像、简介、语气、故事、视觉统一生成。

如果 project id 不存在，很多插件不会直接报：

```
project missing
```

而是：

```
agent executor error
request failed
loading forever
```

所以看起来像：

- 网络问题
- 模型不回复

其实是 **project 没绑定**。

---

## 一个小细节（很多人不知道）

Antigravity 有 **两个 endpoint**：

```
daily-cloudcode-pa.googleapis.com
cloudcode-pa.googleapis.com
```

前者是 sandbox。

有些账号如果 **没有 project**，sandbox 会直接拒绝。

---

## 总结一句话

你遇到的情况其实是：

**Google 没给你自动创建 Cloud Project。**

所以：

```
别人账号
→ 自动 project
→ 不用填

你的账号
→ 没 project
→ 必须手动填
```
