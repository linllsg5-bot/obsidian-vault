如果你说的是 **A6 里看到的 `Claude Fable 5.1` 和 `Claude Fable 5-1`**，那它们大概率**不是两个不同模型**，而只是命名方式不同。

Anthropic 官方的正式模型名是 **Claude Fable 5.1**，而 API 的 model ID 写成：

`claude-fable-5-1`

也就是说：

**5.1 = 面向人的版本号写法**  
**5-1 = API / 路由里的机器标识写法**

Anthropic 官方文档也明确把 `Claude Fable 5.1` 对应到 `claude-fable-5-1`。citeturn541029search0turn541029search4

```text
界面显示：Claude Fable 5.1
A6 路由：a6/claude-fable-5.1
Anthropic 原始 ID：claude-fable-5-1
```

本质都指向 **Fable 5.1**。
