from playwright.sync_api import sync_playwright
import json

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)  # 无头模式
    page = browser.new_page()

    # 监听所有 response
    responses = []

    page.wait_for_timeout(5000)  # 等 5 秒让 JS 完成加载

        print(url)
        print(json.dumps(data, indent=2))

## assistant

如果你想找到一个网站背后的 JSON API，本质上是在寻找网站前端和后台交换数据的通道。方法可以有几种，但关键是观察浏览器与服务器之间的网络通信，而不是猜 URL。步骤可以这样来操作：  

---

### 1. 打开浏览器开发者工具
- 在 Chrome / Edge / Firefox 中按 **F12**，或者右键 → “检查”。
- 选择 **Network（网络）** 面板。
- 勾选 **XHR / Fetch**，只显示异步请求（通常 JSON API 都是异步请求，不是页面 HTML）。

---

### 2. 刷新页面并操作
- 刷新网页或者点击某个按钮，让页面加载数据。
- Network 面板会显示很多请求，通常 JSON API 会返回：
  - **Content-Type**: `application/json`  
  - **Response**: 看起来像 `{"data":[...]}`
- 注意请求的 **URL** 和 **Method**（GET / POST）。

---

### 3. 分析请求参数
- 查看请求参数（Query String、POST 数据）：
  - 可能有 `id`、`page`、`limit` 之类分页参数。
  - 有些需要特定的 `headers` 或 `cookies` 才能访问。

---

### 4. 测试 API
- 可以复制 URL 到新标签页或用 `curl` / `requests` 测试。
- 如果需要登录或带 Cookie，需要把请求头加上去。
- 返回 JSON 的就是你要找的接口。

---

### 5. 补充技巧
- **搜索关键字**：有时网页 JS 里直接写了接口地址，可以在 Sources 面板搜 `.json` 或 `/api/`。
- **抓包工具**：Charles、Fiddler、Wireshark 可以抓到浏览器所有网络请求，更直观。
- **动态生成的 URL**：一些网站会用加密 token，你可能需要模拟登录或 JS 执行环境。
