## 🌱 **WSL 是什么**
WSL 全称是 **Windows Subsystem for Linux**，就是**在 Windows 系统里跑一个完整 Linux 内核环境**，而且不需要虚拟机（像 VirtualBox 那样）或双系统重启。  

你可以把它理解成：  
✅ **一个轻量级的 Linux 环境**，装在 Windows 里  
✅ **可以直接用 Linux 的命令和软件**（比如 apt、gcc、python）  
✅ 和你的 Windows 文件系统可以互通（/mnt/c/ 就是C盘）  
✅ 像容器一样用的时候很“干净”，不影响 Windows 主系统  

🆚 **和 Docker 的区别**  
| 特点               | WSL                                    | Docker                                |
|--------------------|-----------------------------------------|---------------------------------------|
| 运行机制           | 模拟完整 Linux 内核环境                | 使用 Linux 容器内核隔离              |
| 系统隔离程度       | 很低，能访问 Windows 文件               | 很高，容器内不能直接访问宿主文件     |
| 适合场景           | 需要 Linux 系统做开发、编译             | 需要快速部署服务/程序（轻量虚拟化）  |
| 是否带桌面         | 默认没有桌面（但可以装桌面环境）         | 没有桌面                             |
| 安装复杂度         | 非常简单                                | 稍复杂，依赖 WSL 或 Hyper-V          |

👉 所以你可以把 WSL 理解成 **一个比 Docker 更“完整”的 Linux 运行环境**。

## 🛠️ **WSL 安装步骤**
### ✅ 1. 检查 Windows 版本
WSL 需要 **Windows 10 (2004及以上)** 或 **Windows 11**  
打开 PowerShell 输入：  
```powershell
winver
```
- 如果版本 >= **19041**，可以装 WSL2（推荐）
- 如果低于，建议升级系统  

---

### ✅ 2. 一键安装 WSL
在 PowerShell（管理员）里运行：  
```powershell
wsl --install
```
这会自动：  
✔ 开启 WSL 功能  
✔ 下载 WSL2 内核  
✔ 下载并安装 Ubuntu（默认）  

装好后重启，第一次运行时它会提示你设置 **Linux 用户名和密码**。

---

### ✅ 3. 验证安装
打开命令行，输入：  
```bash
wsl --list --verbose
```
如果显示：  
```
Ubuntu    Running    2
```
说明 **WSL2 + Ubuntu 安装成功**

进入 Linux 环境：  
```bash
wsl
```
你现在就在 Ubuntu 里了，可以用 `apt update` 装软件了。

---

### ✅ 4. （可选）切换到 WSL2
如果系统默认是 WSL1，升级到 WSL2：  
```powershell
wsl --set-version Ubuntu 2
```

---

### ✅ 5. （可选）图形界面（桌面环境）
WSL 默认是命令行，没有桌面。  
如果你想要 Linux 桌面体验，可以装：  
```bash
sudo apt install xfce4
```
然后用 Windows 的 **WSLg** 或 XServer（VcXsrv）显示桌面。

### 🔌 **三种常见接法**
#### 1️⃣ **ESP32 通过 HTTP/MQTT 请求 AI 服务器**
- **结构**：
  ```
  [ESP32] ⇄ (WiFi) ⇄ [AI服务器: GPT/Mistral/本地部署大模型]
  ```
- **流程**：
  1. ESP32 发送 HTTP 请求（或 MQTT 消息）到 AI 服务器。
  2. AI 服务器处理请求，返回响应（文本/动作指令）。
  3. ESP32 根据指令控制硬件。

- **优点**：
  - 简单。
  - 兼容 ChatGPT/OpenAI API、FastAPI、Flask 自建API。
- **缺点**：
  - 必须有稳定网络。

- **ESP32 代码示例（HTTP请求）**：
  ```cpp
  #include <WiFi.h>
  #include <HTTPClient.h>

  const char* ssid = "你的WiFi名";
  const char* password = "你的WiFi密码";

  void setup() {
    Serial.begin(115200);
    WiFi.begin(ssid, password);

    while (WiFi.status() != WL_CONNECTED) {
      delay(500);
      Serial.print(".");
    }
    Serial.println("WiFi connected");

    HTTPClient http;
    http.begin("http://your-ai-server.local:8000/api");
    http.addHeader("Content-Type", "application/json");
    int httpResponseCode = http.POST("{\"input\": \"Hello AI\"}");

    if (httpResponseCode > 0) {
      String response = http.getString();
      Serial.println(response);
    } else {
      Serial.printf("Error: %d\n", httpResponseCode);
    }
    http.end();
  }

  void loop() {}
  ```

#### 2️⃣ **在本地运行小模型 + ESP32 串口通信**
- **结构**：
  ```
  [ESP32] ⇄ (UART/USB) ⇄ [PC运行大模型或轻量模型]
  ```
- **适合场景**：
  - 如果不能上网，可以用 PC（或树莓派）运行模型。
  - ESP32 只做数据采集，PC AI 处理。

- **PC端可以用**：
  - Python + LLaMA.cpp
  - Ollama（运行 GPT4All、Mistral 等小模型）
  - HuggingFace Transformers

- **Python 串口代码示例**：
  ```python
  import serial
  from transformers import pipeline

  ser = serial.Serial('COM3', 115200)
  chatbot = pipeline("text-generation", model="gpt2")

  while True:
      if ser.in_waiting > 0:
          msg = ser.readline().decode().strip()
          print(f"ESP32: {msg}")

          # 让AI生成回复
          reply = chatbot(msg, max_length=50)[0]['generated_text']
          ser.write(reply.encode())
  ```

### **3️⃣ ESP32 接入局域网**
✔ **步骤**
- 用 Arduino IDE/ESP-IDF 开发 ESP32 程序
- 配置 WiFi 连接服务器

✔ **操作（Arduino 示例）**
```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* ssid = "你的WiFi名称";
const char* password = "你的WiFi密码";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);

  // 连接WiFi
  while (WiFi.status() != WL_CONNECTED) {
    delay(1000);
    Serial.println("连接中...");
  }
  Serial.println("WiFi已连接");

  // 发送HTTP请求
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin("http://你的服务器IP:8000/chat");
    http.addHeader("Content-Type", "application/json");

    String payload = "{\"prompt\":\"Hello AI\"}";
    int httpResponseCode = http.POST(payload);

    if (httpResponseCode > 0) {
      String response = http.getString();
      Serial.println(response);
    } else {
      Serial.println("请求失败");
    }
    http.end();
  }
}

void loop() {
  delay(10000); // 每10秒请求一次
}
```
