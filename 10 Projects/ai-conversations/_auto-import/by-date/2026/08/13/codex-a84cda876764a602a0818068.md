## 研究对象与评价方法

核心主张分为八组：

- 新存在何时算开始存在；
- 认识论如何成为实际运行内核；
- 内核共识与空间共识如何形成而不制造思想克隆；
- 沟通如何产生主体联合、调度、执行与现实返回；
- 学习和位置轮转如何表现为跨轮结构变化；
- 主体、对象、关系和世界映射怎样生成与改变；
- schema 与软件架构如何进入组织的自我认识和自我修改；
- 可能/“幻觉”、尝试与现实落地之间的关系。

每项主张使用统一研究记录：

- 原始表述、说话人、来源锚点；
- 当前认知地位和作用域；
- 后续纠正或替代；
- 最近学术/技术先例；
- 真重合、关键差异、误认风险；
- 最强支持与最强反例；
- 需要怎样的软件实验才能继续成立；
- 对第一版设计的影响。

这只是研究档案格式，不作为 Cognos 的产品本体或固定 schema。

原创性采用双标尺：

- `N0` 已有常见命题；
- `N1` 有辨识度的重新解释；
- `N2` 独特但未证明的综合；
- `N3` 可信的潜在新研究命题；
- `N4` 经对照实验支持的原创贡献。

证据成熟度另记为：

- `E0` 愿景或断言；
- `E1` 有来源与论证；
- `E2` 经近邻和反方区分；
- `E3` 经原型对照验证；
- `E4` 可复现或经外部评议。

不允许用理论新颖性代替证据成熟度。

## 来源与质量要求

- 当代产品与开源系统只采用官方文档、论文和代码仓库核实，并记录检索日期。

8/8“创作特质被误认成 Attempt”只保留为错误对象化回归测试，不再承担整个第一版的主证明任务。

### 6. 主要矛盾与开放问题

1. **关系的一等地位 vs 空间依附**  
   关系可以有存在地位和历史，但不等于可以脱离空间成为全局实体。工程表示需要同时满足两点。

2. **空间是关系结构 vs 数据库中的空间容器**  
   把 Space 做成容器、Relation 做成内含记录只是第一阶段妥协，不能冒充已解决自指问题。

3. **不固定最小单位 vs 固定五对象 schema**  
   既然最小单位取决于“何时不能被忽视”，固定五表只能是暂时索引结构，不能写成思想的直接实现。

4. **主体有门槛 vs 五级 subject_level**  
   小林确认了门槛问题，没有确认五个离散等级，也没有确认主体化是单轴线性过程。

5. **多种关系显现 vs 四级显现**  
   “显现情况有很多”不推出 0–3 等级。显现可能是多维、情境性或不可比较的。

6. **原语不能标签化 vs Movement 类型枚举**  
   `judgment/attempt/learning` 等字段很容易把认识论原语降成消息标签。记录痕迹与认知解释必须分开。

7. **学习是主体完整变化 vs 外部记忆模拟**  
   小林接受模拟作为边界，但尚未说明何种“下一次改变”足以算学习雏形。

8. **调度是联合 vs 表单化 Dispatch**  
   联合邀请结构可能有用，却不能仅靠字段名称证明主体联合发生。

9. **架构在沟通中生成 vs Agent 外接延后**  
   小林已经指出沟通对象包含 Agent，并可进行更改。若第一版长期只有聊天而没有实际执行/修改，便违背已确认方向。

10. **阶段性共识 vs 最终治理权**  
    “达成阶段性共识，然后决定执行”是小林原话；“非对称共同生成、小林最终裁决”的正式治理结构还需跨 ex.1–2 核验。

11. **上下文防遗忘 vs 新存在开始运动**  
    上下文构建只是必要器官，不能成为首要存在证明。

12. **Web 第一版 vs Tauri 桌面技术栈**  
    ex.3 的明确选择是 Web；Tauri 只能是未来包装候选。

13. **Agent 参与 vs API 模型网关**  
    小林想接入 Codex/Antigravity/Claude Code 等 Agent，而计划多次退化成 Claude/OpenAI API。两者是不同执行架构。

14. **世界映射是项目重点 vs 第一版只做组织内存储**  
    可以延后完整世界映射，但第一版至少要保留现实反抗和外部结果返回的位置，否则会继续内循环。

15. **“其他还好”造成的假确认**  
    小林在 E3-04 已明确：“没提到的……先默许了，但是也不怎么认可、赞同，可以继续。”所以沉默和继续都不能升级为确认。

### 本波短裁决

- **已经确认**：关系的空间依附、调度作为主体联合、学习作为完整展开、主体门槛、生成式分层、动态位置、沟通内架构设计、分阶段 Web 动手。
- **被先前方案错误替换的内容**：CLI 防忘被当成第一器官；关系被当成全局边或独立漂浮实体；主体门槛被替换成五级字段；显现多样性被替换成四级枚举；Agent 行动被替换成模型 API 对话。
- **仍有区分度但未实现**：组织的沟通怎样形成主体联合并触及现实、现实返回怎样改变下一轮、软件怎样在自身沟通内生成和修改架构。
- **仍未定案**：完整数据模型、技术栈、记忆权威结构、治理方式、世界映射、第一版存在判据。
- **对后续研究的要求**：不要把 `ObjectInSpace + space_id + subject_level` 当作 ex.3 已确认基线；它们只能作为受约束的工程候选接受外部先例与反方检验。
