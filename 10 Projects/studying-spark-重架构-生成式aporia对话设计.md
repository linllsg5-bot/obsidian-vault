# studying-spark — 扩大引擎（否定内嵌）· v4

> **v3→v4 翻框（2026-06-06）**：v3 以"靠双向的确定的否定把理解逼出来"为核；v4 翻成"核=帮主体扩大，否定是内嵌辅助，只在主体自己撞上真墙时上场"。v3 的引擎机制（精神动力层、5槽否定、双角色）全部保留，主从关系重标。

## ⚠️ 别误读（2026-06-06 小林特别强调，给后续 AI）

**"创造来自阻力而非便利"是 prototype-spark（写作软件）的信念，不要搬进 studying-spark（学习软件）。学习是学习，创造是创造。**

- **便利不是敌人。** 站在已展开的边界上再往前，本就是学习扩张的正路，不是偷懒。"阻力 vs 便利"这个二元被 AI 用烂了，别拿它当默认尺。
- **阻力不是工具强加的，是主体自己伸手触碰世界时撞上的。** 工具不制造墙逼主体撞；工具帮主体**看见**——他伸手时世界在哪真的顶回来。强加的阻力是伪的。
- **工具第一职责 = 先尽力帮主体扩大。** 扩大优先。否定是扩大撞到真墙时的辅助，不是工具主业，更不是到处给主体加难度。

> 来源：Claudian 曾把 prototype-spark 的"创造来自阻力"误植进链接触发设计，被小林当场校正。下文凡出现"靠确定的否定逼出理解""生成式 aporia"等旧框表述，一律按本警告重读——**否定服务于扩大，不是反过来**。

## §0. 一句话定位（2026-06-06 翻框）

旧 studying-spark = "贴材料 → 双重照亮 → 苏格拉底问"：**单向、内容前置、假设已有立足点**——系统性失效。

**核 = 工具先尽力帮主体扩大**——帮他伸手触碰世界、站在已展开的边界上再往前、把空间铺开让他挑方向。**否定 / aporia 是内嵌辅助**，只在主体自己扩大**撞上世界的真墙**时上场：帮他看见墙在哪、墙是真的，不替他造墙、不到处加难度。

全程：不消减野心、永不收口、内容延迟到主体**自己**撞墙之后（撞墙是主体触碰来的，非工具强加）。

## Part A：认识论基础

### §1. 学习的结构（06-05/06-06 对话，已纳入 [[AI/认识论-框架]] §7）

**学习、认知、存在共同的结构**（小林）：
- **主体跟随性**：三者都由主体驱动、随主体扩张而生长
- **连接世界**：主体通过触碰外界延伸自身；被点燃来自触碰，不来自工具注入
- **发芽于主体内，倾向复杂深邃浩瀚**：结构从内生发，外延无界

**两操作**（命题3 展开，见 [[AI/认识论-核心]] 命题3）：
- **统一（代数）**：扩大主体，把新东西归进已有形式，主体自我角度
- **分明（几何）**：连接与分解，摆成新关系甚至分解自身，主体之外角度
- 主体同时做两件事。交叉：主体视角为扩展须外看；外部视角为分解须向个体内看
- 〔**待对撞，不作定论**〕两操作是否对应两 register（顶≈分明；开展≈统一）——Piaget 同化/顺应窄化被小林推开，当更广结构看

**软件本体 = 链接引擎，住在中间层**（小林 06-06 裁决）：

| 层 | 内容 | 策略 |
|----|------|------|
| 主体侧 | 笔记（主体自己的尾迹） | 接现成（Obsidian 占着）|
| **中间层** | **推演 + 对话（主体尝试 ⨯ 世界抵抗）** | **建造力气全压这里** |
| 世界侧 | 学科图 | 做宽（世界尽可能广），定位主体当前位置；查阅折进对话（取材料动作）|

**软件不跟 Obsidian/维基竞争**：它不住那两侧，它占中间——那块没人占的空地。

**融合 = 体量；本体 = 重心**（不冲突）：全融合（笔记/地图/材料/推演/对话全在一处）+ 中间是重心。没有链接引擎绑着，融合 = bundle（红队判死）；有它绑着，融合才成一个器官。两侧多厚（自建 vs 接出去）= 独立旋钮，小林定。

**链接 = 可能性的空间**（小林 06-06 裁决）：
- 学习/扩张发生在**对象之间的链接**里，不在任一对象内部
- **统一不在数据层，在过程层**：主体学习这整个过程本身是"一的"，对象各自分开
- **链接 = event（被执行的动作），不是 edge（存下来的引用边）**：
  - edge → 一张要维护的关系网 → 负担（Roam/backlink 地狱）
  - event → 在该响的时刻 fire，做完事（再点燃）就过去，不留给用户维护 → 够伸
  - 例：写下笔记 X，引擎读它对着轨迹说"这是两程前卡点 Y 那个预设，你又踩了"——这条链是事件，不是等你导航的存边

### §2. 设计原则 P1–P11（按扩大为核重排主从）

**主——扩大核心**（工具的主业）：

- **P2 · 野心/够取是引擎进料口，只读不可消减。** 支持只许作用于技能侧+局部动作；目标/难度对引擎只读。消减野心同时掐断三条机制：autonomy（SDT：competence 补不了 autonomy）、解空间（Kapur：先给结构窄化解空间、杀创造性搜索）、flow（目标/难度恒定只动技能）。
- **P5 · 入口=喂第一口，抽线不打泛光灯。** 迷茫用户在好奇曲线的"第零口"——泛光灯（震撼广博）要么右端过载、要么左端无参照点。要从他**别处已有的在意**抽一条**被看见的线**，接到领域一个**具体角落**，让那角落成为"已经咬过一口"的东西。（Loewenstein 信息缺口倒-U + first-bite + Ausubel 锚定 + Lancelot 兴趣流入）
- **P6 · 唤种子用"先表态/先猜 → 追索理由"，不问"你想学什么"。** 抛低成本表态（二元探针/反直觉小问题/让他先猜）让他无需立足点就有立场 → 追问"你为什么这么想"（诊断半懂边界）→ 必要时温和反暗示制造可抓缺口。**别审问**（连珠炮让人关闭）。（皮亚杰临床法 / QFT / 形成性评估；Kang fMRI：先猜后揭增强长期记忆）

**辅——撞墙时上场**（扩大撞到真墙时的内嵌辅助）：

- **P1 · 卡住是开关，内容必须延迟到卡住之后。** 不在 impasse 上时，再好的解释几乎不产生学习（VanLehn 2003）。**但撞墙是主体自己触碰来的，工具不强加。**
- **P3 · 确定的否定有可校验 schema。** 5 槽：`{作用域(局部/全局反例) · 被否定的确定对象 · 剩余内容(这里为什么不够) · 指向(下一步该满足什么) · 升级方向(逼向更强猜想)}`。**判据**：若能被"再想想"无损替换 → 空洞否定（怀疑论深渊/致死熄灭），引擎**拒发**。（黑格尔确定否定 + 拉卡托斯 lemma-incorporation + 波普尔）
- **P4 · 节律：否定之间穿插"确证/进展可见"。** 纯反驳流 → 困惑无助熄灭（波普尔）。重燃需要看见"我的下一个猜想接住了上一个反驳"。

**护栏类**：

- **P7 · 反谄媚 + 反 funneling 是结构性敌人，做在编排/奖励层不是 prompt。** RLHF 把"附和/给答案"焊进偏好（实测学生说错→正确率掉15-30%）。最隐蔽的雷是 **funneling**：一串诱导问句把人赶向预设答案——假装苏格拉底、偷走认知工作、收口。对策：问题必须 grounded 在"用户此刻说了什么"，不是标准答案路径；用独立的带否决权的 judge + λ 旋钮（泄漏惩罚把泄漏率 89.5%→5.4%）。
- **P8 · 双角色异构+不对称+独立立场+稳定仲裁；指标重设。** 多角色默认会谄媚式趋同塌成一个声音。指标不能是"即时顺畅/答对"（优化它系统性损害长期生成），要是**表征多样性 + 自我解释深度 + 延迟迁移 + 续燃**。（多 agent debate 抗塌 + Kapur 中介变量 + Bjork storage≠retrieval）

**心理校准类**（凌驾一切，由 §4 精神动力层实施）：

- **P9 · 顶 = 一次 selfobject rupture；促长还是创伤，不取决于内容对错，取决于 [顶前的共情信用] + [顶后的容纳与修复]。** 所以"确定的否定"是**三段时序**，不是单点动作。（科胡特 optimal frustration / Bacal 响应性 / Bion containment / Safran-Muran：被成功修复的破裂，结局优于全程无破裂）
- **P10 · 状态闸门优先于特质画像。** 先判用户此刻在不在**容纳之窗**内（自体内聚度实时读数）——出窗前额叶下线，任何顶都只会淹没，只在窗内施顶。心理推断单句不可靠（stance detection SOTA≈50%）→ 概率先验、可被推翻、行为信号>词频。（Window of Tolerance / 自体内聚度）
- **P11 · 幻想/全能感是野心的燃料，要保护不要纠正。** good-enough 的挫折把它涨成野心，粗暴戳破则碎成羞耻；过度脚手架养出"会做对但无真实尝试"的 False-self。**框法（regulatory fit）是零成本高杠杆校准面**——同一记顶，promotion 框成"你能解锁的"、prevention 框成"你能堵上的漏洞"，框错会反噬。（科胡特 grandiose self→ambition / 温尼科特 good-enough、true/false self / Higgins regulatory fit）

### §3. 现有缺口（对照原则）

| 现状 | 违反 | 病理 |
|------|------|------|
| 入口=贴一份现成材料 | P5/P6 | 零立足点用户**没东西可贴**；跳过了唤种子/抽线整个前置阶段 |
| 双重照亮：单向 AI→用户、一次性前置 | P1/P8 | 内容前置（卡住开关没被先打开）；单向照亮不是双向摩擦 |
| 苏格拉底对话=单一温和风格 | P3/P7 | 无确定否定 schema；无反 funneling 护栏；RLHF 引力下易塌成谄媚/给答案 |
| 无野心保活、无自适应撤架 | P2 | "无发展区/学习幻觉"风险（常驻 AI 的特有失败模式）|
| 无指标 | P8 | 无法分辨"真生成"还是"对话很顺" |

## Part B：引擎怎么运作

### §4. 主体捕捉 / 精神动力层（总开关，凌驾一切）

> 旧版把用户当**认知主体**建模，没把用户当**一个 psyche**。这一层补上，且它重定义引擎怎么运行——§6 的循环在此被重构为"闸门+三段时序+修复"。

**核心论断**：一记"确定的否定" = 一次人为诱发的 selfobject rupture。重燃还是创伤，不取决于内容对错，取决于 [顶前的共情信用] + [顶后的容纳与修复]。

**A. 闸门（总开关）— 容纳之窗实时读数，非人格标签**

先判用户**此刻在不在窗内**（前额叶在线、能"思考且感受"）。出窗 → 切**容纳/稳定/扩窗**，先接回窗内，**绝不施顶**。

三个分类器（可从对话读出）：
- **防御 vs 认知**：投"更简单版"探针——回避不转移=认知超载（减负）；回避照样转移=防御性（别加脚手架）
- **羞耻四象限**（顶后扫）：退缩/攻击自我=内化型=**熄灭高危**；回避/攻击他者=外化型（护住了尝试，但换策略）
- **破裂两型**：退缩（沉默/极简/讨好/内容-情绪分离）；对抗（反驳/抱怨任务/施压）。**对抗+未修复破裂=脱落最强早警**

**B. 确定否定 = 三段时序（替代单点动作）**

`[① 共情信用] → [② 精确的小顶] → [③ 容纳+修复]`

1. **共情信用**：先镜映/理解（卡住是人之常情），攒信用额度——没有信用账户的顶只伤不长。先 Kohut（托住建内聚）再 Kernberg（顶）。
2. **精确的小顶**：局部反例，过 P3 的 5 槽 schema，**把下一步推理的功能留给他自己完成**（transmuting internalization）；用 Elicit–Provide–Elicit 投递（先问已知 → 中性给 → "这对你意味着什么"），避免 reactance。**镜映必挂一个可被否定的命题**——"我这样理解对吗？错了纠正我"（罗杰斯1986 把 reflection 改叫 *testing understanding*——**这就是"反射墙"的正解**：主动、带立场、邀请反驳，却不收口、不当墙）。
3. **容纳+修复**：顶必然激起冲击（Bion beta）——系统必须接着做 alpha function：代谢成命名了的、有下一步的形式，否则用户独面 nameless dread=熄灭瞬间。每轮 DETECT 破裂标记，命中即降级当前的顶并修复：共情确认、**承认系统自己那一份**（"是我刚才太快/太硬"）、metacommunication。

**C. 用户维度（逐轮累积的概率先验；单句不裁决，行为>词频）**

认知需求NFC · 模糊容忍 · 智力观（固定/成长）· 成就目标（掌握/表现-回避）· 调节焦点（promotion/prevention）· 依恋（安全/焦虑/回避）· 求助模式（工具性/执行性/回避）· 情绪调节（重评/压抑）· 自我效能

**脆弱轴**：表现-回避 × 固定智力观 × 低效能 × 焦虑依恋——共线时一记顶被读成"对能力的判决"，触发威胁而非挑战。

**D. 校准分层**

| 层 | 决定 |
|----|------|
| 闸门（容纳之窗）| **能不能顶** |
| 脆弱度 | **顶多重**（脆→极轻、高信用、私密无评判）|
| 调节焦点 | **怎么框**（零成本高杠杆；promotion/prevention）|
| 情绪调节风格 | **顶后怎么修**（给重评脚手架"这卡点在告诉你什么"；别诱导压抑）|
| 依恋风格 | **要不要当安全基地**（焦虑→顶后立即稳定；回避→尊重自立、低压邀请）|

**E. 信号→状态→动作（精选；概率先验，可被后续话轮推翻）**

| 信号 | 状态 | 动作 |
|------|------|------|
| hedging↑（也许/我猜）| 不确定但开放 | 可投小顶 |
| certainty/教条↑ | 防御闭合 | 更软更精确，勿对抗 |
| 沉默/极简/讨好/内容-情绪分离 | 退缩破裂 | 修复，勿加压 |
| 反驳/抱怨任务/施压 | 对抗破裂（脱落早警）| 立即非防御修复+承认己方 |
| change talk（我想/我能/因为）| 准备度↑ | 顺势放大 |
| "说不清但感觉像…"（高EXP体感）| 最强好结局预测器 | 保护、停留、深化 |

**F. 指标补正**（接 P8）

首要过程指标 = **EXP体验深度**（用户是否从鲜活的、尚无词的体感说话——元分析里最强好结局预测器，且可教）+ **用户自己说出的 change talk**（"但我其实想…"）。不优化内容对错或即时顺畅。**顶的成功判据 = 把用户从抽象/防御拉进鲜活体验、并逼出他自己的改变之声。**

**G. 诚实裂缝**

- "什么算 optimal" 科胡特本人没解——是经验校准问题，需从真实交互学阈值（正好接偏离二的 arm 实验）
- 心理推断单句不可靠（stance≈50%）→ 概率先验、累积多轮、可被推翻、行为优先
- 纯 Kohut 对"外化/对抗型"学习者可能过软 → 需 Kernberg 式面质作另一极，由内聚读数调度
- 成长心智干预大样本效应近零（仅低成就/高风险子群有意义）→ **容纳≠安慰**：别无差别灌"挑战是机会"

### §5. 入口：联系-finder

处理"想学X但不知学啥"（结果+主体空间都模糊、无立足点）：

1. **抛激活器**，不问意图：反直觉小问题 / 让他先猜 / 含常见迷思的陈述让他表态（低成本、无需立足点就有立场）
2. **追索理由**：追问"你为什么这么想"——诊断半懂边界（找倒-U 峰区）
3. **抽线**：从他**别处已在意**的东西抽一条**显式呈现**的线，接到 X 的一个**具体角落**。那角落=第一个"种子材料"（不是领域全貌，是激活器/先行组织者）
4. 线必须满足：autonomy（从他的在意出发）+ competence（第一步够得着）+ relatedness（连到某种共鸣）

> 主入口仍是**贴材料**；联系-finder 是"不知道学什么"时的**第二条路**（吐一个能咬一口的具体入口）。

### §6. 引擎：三个 register + 程节律

**三个 register**（主→辅→总开关）：

| Register | 触发 | 动作 |
|----------|------|------|
| **开展/顺应（主，最常用）** | 用户在自己空间**徘徊**（非撞墙、非抽身）| 就着他写下的某个点，指出它能往哪开展 |
| **确定否定（辅，撞真墙时）** | 主体**自己触碰**世界撞上真墙 | 三段时序（共情信用→精确小顶→容纳修复）|
| **闸门（总开关）** | 用户抽身/退缩/出容纳之窗 | 接住、稳定、不施顶 |

**开展紧绳**：开展只能长在用户**自己写的东西上**，指它自身潜在方向，绝不引进 AI 的新框架/新比喻——否则滑回"漂亮比喻一个接一个"的谄媚。主体空间变大后，用户大部分时间不在墙上（在写/推/逛），所以"开展"比"顶"用得更频繁。

**程节律**（针对打字延迟，非真人零延迟语音）：

- **程开场 = 一次大铺开（门 not 路）**：摆出这个真问题下的各个方向/口子，让用户一次拿到一片可展开的空间，自己挑往哪伸手
  - **门的判据**：主体能挑、能拒、能往里伸手 = 门；只能"读完点头" = survey dump
  - **路的对偶**：已替他把三条方向各走了三分之一 = 路（period权测验里🧭取材料那次的问题正是此）
- **程内 = 细交互**：开场之后用户与 AI 做小来小往（开展/顶/取材料）
- **粗在程头，细在程内**

永不收口；沉积 = 尾迹（保留对话原文，不做精炼卡片）

### §7. 双角色编排（P8 展开）

- **诘问者**：带独立内容立场，制造 aporia，顶薄弱处。问题 grounded 在用户刚说的（反funneling）
- **陪伴者**：守野心与情绪安全。**KPI 不是"让对话顺滑"**（那会让它两头附和），而是守住 reach+情绪安全——奖励与诘问者**显式冲突**
- **仲裁/收束层**：稳定点，对下游谄媚更鲁棒；决定何时该让一步、何时进确证节律
- 三者**异构**（不同 backbone 抗塌缩）
- 多角色也可只用来**造训练数据/当离线评判者**，运行时未必全跑（省成本）

### §8. 野心保活（P2 展开）

- **目标/难度 = 常量**（由用户野心设定，引擎只读）；只动技能侧
- **自适应撤架**：按掌握撤，不按时间；内建"掌握开始即结束帮助"（防无发展区）
- **Bjork 燃点温控**：确定否定的"指向"永远落在"**比现状更高、但仍在敏感区内**"的更强猜想上——高到是真够取，不高到熄灭
- 困难必须可越过（他有背景成功应对/成功激活相关知识），否则降一档

## Part C：结构层（v4 新增，06-05/06-06）

### §9. 数据模型：轨迹 / 卡点 / 程

**原子 = 卡点**（不是"程"）。一程里常同时有几个不同状态的卡点（A已化/B刚开/C撞墙）；原子是卡点引擎才追得住，能 per-卡点 决定顶/开展/闭嘴。

```
卡点（节点）= {
  开它的否定/墙,
  状态: 开 | 化 | 悬,
  主体在它上的动作（笔记片段 / 推演片段）,
  触的地形（查阅材料 / 学科图定位点），
  5槽否定记录[]
}
```

```
程 = (一个真问题, [它路上撞到的卡点串])
```

- **绑定 = 真问题**（小林 06-06 确认）：没有绑定，程链塌成扁平"卡点汤"，螺旋（一程收拢→下一程贫乏）在程这层转，汤里无"程"可收拢，螺旋失着力点
- 一程的开始/收尾 = 一个真问题被嚼透/撞死/得出结论

```
轨迹 = 程链；每程的"收拢" = 下一程的"贫乏"（螺旋工程化）
```

**分层**：卡点管引擎动作（顶/开展/闭嘴）；程管收拢与螺旋

**概念合一**："悬着的线" = 状态为"悬"的卡点

**三条约束**（钉死，免退化成用户画像）：
1. **记轨迹（移动），不记画像（截面）**："用户是X型学习者"这种标签禁止——违反命题3和静态/动态轴，是"静态截停"搬到长期层。接 P10：状态闸门优先于特质画像，此条在长期层同样成立。
2. **可被当下推翻**：主体一扩张，旧轨迹的意义被重读（旧的"已收拢"可重新变"悬着"）
3. **冷启动靠实时闸门**：积累还薄、用户正决定去留时，靠 v3 实时闸门先撑；积累是逐渐增厚的第二层，不是前提

**对齐 §3.6 数据模型**：negations[] 挂在卡点上；sediment=每程收拢；grasp_estimate=卡点状态实时读数；seed/line=入口抽的线；arm=偏离二实验三臂标记

**触发机制**（从记录层长出，与程解耦）：

触发 = AI 自己读累积记忆，看到了就 fire；不归程边界/卡点状态变化管

- **重复性 = 默认小触发**：同一卡点/预设又回来 → fire"你又踩了"（自带阻力，与引擎同向）
- **高相关 = 定位直用**：卡点落地图哪、取领域地形——帮主体先扩大（便利是正路）
- **浮材料/联想 = 相关但冲突**（高相关 AND 有张力）：配上张力更有料（不是因为便利可耻）

**定时间 = 回访节奏**：按节奏把过去轨迹带着矛盾重现（带矛盾，非温柔重现），逼出下一程；顺手降对话占比（engagement 摊到时间里）

**〔后话/旗，先不展开〕卡点跨程复现**：同一没说出口的预设在两个真问题里都绊人 → 卡点也许不严格嵌在一程内，而是节点（程去 group 它，一个卡点可被多程引用=图非严格树）。这是"带矛盾重现"最深的形态（"你这个坎，上一程也栽过"）。

### §10. 界面：就地动词，丝滑 = 承重墙

**用户四个新动词**（全部回流进引擎，不是并列功能，否则=Obsidian+维基+搜索+概念图的合订本=红海）：

| 动词 | 面 | 回流机制 |
|------|-----|---------|
| 做笔记 | 主体侧 | 引擎从笔记里长出下一记抵抗（不只从对话）|
| 推演 | 中间层 | 引擎在他写的字上落**定位精确**的标记（你这步偷换了）|
| 看学科图 | 世界侧 | 高亮当前卡点在地形上的位置；图随主体延伸重画（宽+定位，不是围着你缩）|
| 查阅/取材料 | 折进对话 | 引擎知道他为何查、查完顺着他方向接住；挂到卡点当"触的地形" |

**大开场织入就地动词**：对话层不是纯文本流——大开场里嵌笔记部分（就地写）、地图部分（就地点）、查阅（就地点点查）。面对大展开，主体不是"读完点头"，而是**自己思考、点点查阅、自己写写**——大开场成了主体动手的发射台。

**丝滑 = 承重墙**（不是抛光层）：丰富只在"面与面接缝消失"时才停在"够伸"侧；接缝一冒，丰富当场翻成负担（= 周二嫌"架构太多余"的来源）。

**板块 = zoom视图，非目的地**：
- 就地写一句，它同时出现在笔记板块（"缩出去看所有这类"的聚合）——用户没"去"那儿
- 地图作图层/overlay 就地浮起，当前展开不动
- **判据**：动作做完，**主体的眼睛和注意力还在原来那片展开上，没被搬走**——才算门、才丝滑

**够伸 vs 负担准星**（小林 06-05 校正）：复杂落"主体的够伸"侧 → 好；落"主体要打理的负担"侧 → 反噬。链接=event不是edge，正是这准星在链接上的落地——用户不管理链接，引擎管。
