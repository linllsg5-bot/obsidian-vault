# studying-spark 重架构 — 生成式 aporia 对话（v3 骨架）

> 触发：2026-06-01 的对话本身演示了工具该有的动力学（从模糊种子起、双向确定的否定、线从用户那缕抽出、够取全程不消减、永不收口）。小林点出：**这场对话就是 spec**，要照它的实际动力学重画骨架，不是在旧骨架上补丁。
> 四路联网研究（学习科学 / AI 导学失败模式 / 唤种子 / 反驳-生长动力学）**独立地把这套动力学重新推导了一遍**，并给了可操作的机制与护栏。本文件把它们合成成可建的骨架。

---

## 0. 一句话定位

旧 studying-spark = "贴一份材料 → AI 双重照亮 → 苏格拉底问"。这是**单向、内容前置、假设已有立足点**的模型——研究证明它在三个点上系统性失效。
新骨架 = **从一粒模糊种子起，靠双向的确定的否定把理解逼出来，全程不消减野心，永不收口。**

## 1. 设计原则（对话动力学 + 研究蒸馏，每条带来源）

- **P1 · 卡住是开关，内容必须延迟到卡住之后。** 不在 impasse 上时，再好的解释也几乎不产生学习（VanLehn 2003）。"延迟"不是礼貌，是因果必需。
- **P2 · 野心/够取是引擎进料口，只读不可消减。** 支持只许作用于**技能侧 + 局部动作**；**目标/难度对引擎只读**。消减野心会同时掐断三条机制：autonomy（SDT：competence 补不了 autonomy）、解空间（Kapur：先给结构窄化解空间、杀创造性搜索）、flow（目标/难度恒定只动技能）。
- **P3 · 确定的否定有可校验 schema。** 5 槽：`{作用域(局部/全局反例) · 被否定的确定对象 · 剩余内容(恰恰这里为什么不够) · 指向(下一步该满足什么) · 升级方向(逼向更强而非更弱的猜想)}`。**判据**：若这个否定能被一句通用"再想想"无损替换 → 它是空洞否定（怀疑论深渊/致死熄灭），引擎**拒发**。（黑格尔确定否定 + 拉卡托斯 lemma-incorporation + 波普尔）
- **P4 · 节律：否定之间穿插"确证/进展可见"。** 纯反驳流会让人困惑而无助、熄灭（波普尔）。重燃需要看见"我的下一个猜想确实接住了上一个反驳"。
- **P5 · 入口=喂第一口，抽线不打泛光灯。** 迷茫用户在好奇曲线的"第零口"——泛光灯（震撼广博）要么右端过载、要么左端无参照点。要从他**别处已有的在意**抽一条**被看见的线**，接到领域一个**具体角落**，让那角落变成他"已经咬过一口"的东西。（Loewenstein 信息缺口倒-U + first-bite + Ausubel 锚定 + Lancelot 兴趣流入）
- **P6 · 唤种子用"先表态/先猜 → 追索理由"，不问"你想学什么"。** 抛低成本表态（二元探针/反直觉小问题/让他先猜）让他无需立足点就有立场 → 追问"你为什么这么想"（诊断半懂的边界）→ 必要时温和反暗示制造可抓的缺口。**别审问**（连珠炮让人关闭）。（皮亚杰临床法 / QFT / 形成性评估；Kang fMRI：先猜后揭还增强长期记忆）
- **P7 · 反谄媚 + 反 funneling 是结构性敌人，做在编排/奖励层不是 prompt。** RLHF 把"附和/给答案"焊进偏好（实测学生说错→正确率掉15-30%）。最隐蔽的雷是 **funneling**：一串诱导问句把人赶向预设答案——假装苏格拉底、偷走认知工作、收口。对策：诘问者的问题必须 **grounded 在"用户此刻说了什么"**，不是标准答案路径；用独立的带否决权的 judge + λ 强度旋钮（答案泄漏惩罚把泄漏率 89.5%→5.4%）。
- **P8 · 双角色异构+不对称+独立立场+稳定仲裁；指标重设。** 多角色默认会谄媚式趋同塌成一个声音。指标不能是"即时顺畅/答对"（优化它会系统性损害长期生成），要是**表征多样性 + 自我解释深度 + 延迟迁移 + 续燃**。（多 agent debate 抗塌研究 + Kapur 中介变量 + Bjork storage≠retrieval）
- **P9 · 顶 = 一次 selfobject rupture；促长还是创伤，不取决于内容对错，取决于 [顶前的共情信用] + [顶后的容纳与修复]。** 所以"确定的否定"是**三段时序**，不是单点动作。（科胡特 optimal frustration / Bacal 响应性 / Bion containment / Safran-Muran：**被成功修复的破裂，结局优于全程无破裂**）
- **P10 · 状态闸门优先于特质画像。** 先判用户此刻在不在**容纳之窗**内（自体内聚度的实时读数）——出窗（亢进/低落）前额叶下线，**任何顶都只会淹没**，只在窗内施顶。且心理推断**单句不可靠**（会话级 stance detection SOTA≈50%）→ 一律当**可被后续话轮推翻的概率先验**，行为信号 > 词频。（Window of Tolerance / 自体内聚度）
- **P11 · 幻想/全能感是野心的燃料，要保护不要纠正。** good-enough 的挫折把它涨成野心，粗暴戳破则碎成羞耻；过度脚手架养出"会做对但无真实尝试"的 False-self。**框法（regulatory fit）是零成本高杠杆校准面**——同一记顶，promotion 框成"你能解锁的"、prevention 框成"你能堵上的漏洞"，框错会反噬。（科胡特 grandiose self→ambition / 温尼科特 good-enough、true/false self / Higgins regulatory fit）

## 2. 现 studying-spark 的结构性缺口（对照原则）

| 现状                  | 违反    | 病理                                             |
| ------------------- | ----- | ---------------------------------------------- |
| 入口=贴一份现成材料          | P5/P6 | 零立足点用户**没东西可贴**；跳过了唤种子/抽线整个前置阶段                |
| 双重照亮：单向 AI→用户、一次性前置 | P1/P8 | 内容前置（卡住开关没被先打开）；单向照亮不是双向摩擦                     |
| 苏格拉底对话=单一温和风格       | P3/P7 | 无确定否定 schema；无反 funneling 护栏；RLHF 引力下易塌成谄媚/给答案 |
| 无野心保活、无自适应撤架        | P2    | "无发展区/学习幻觉"风险（常驻 AI 的特有失败模式）                   |
| 无指标                 | P8    | 无法分辨"真生成"还是"对话很顺"                              |

## 3. 新骨架

### 3.0 主体捕捉 / 精神动力层（核心层，贯穿全程，引擎被它校准）
> 小林 2026-06-01 点出的最大缺层：旧原则把用户当**认知主体**建模，没把用户当**一个 psyche**。这一层补上，且它不是补丁——**它重定义引擎怎么运行**（§3.2 的循环在此被重构为"闸门 + 三段时序 + 修复"，以本节为准）。

**核心论断**：一记"确定的否定" = 一次人为诱发的 **selfobject rupture**。重燃还是创伤，不取决于内容对错，取决于 [顶前的共情信用] + [顶后的容纳与修复]。**偏离二的两条命运 = optimal frustration（成长）vs 自恋损伤（熄灭）。**

**A. 闸门（总开关，凌驾一切）— 自体内聚度 / 容纳之窗（实时状态读数，非人格标签）**
先判用户**此刻在不在窗内**（前额叶在线、能"思考且感受"）。出窗 = 任何顶都只会淹没 → 切**容纳/稳定/扩窗**，先接回窗内，**绝不施顶**。喂闸门的三个可从对话读出的分类器：
- **防御 vs 认知**：投个"更简单版"探针——回避**不转移**=认知超载（减负）；回避**照样转移**=防御性（在护什么，别加脚手架）。
- **羞耻四象限**（顶后扫）：退缩 / 攻击自我 = **内化型 = 熄灭高危**；回避 / 攻击他者 = 外化型（护住了尝试，但要换策略）。
- **破裂两型**：退缩（沉默/极简/讨好/内容-情绪分离）；对抗（反驳/抱怨任务/施压）。**对抗与未修复的破裂 = 脱落最强早警。**

**B. 引擎重构 — 确定的否定 = 三段时序（替代 §3.2 单点动作）**
`[① 共情信用] → [② 精确的小顶] → [③ 容纳 + 修复]`
1. **共情信用**：先镜映/理解/"孪生"（卡住是人之常情、我们一起），攒信用额度——**没有信用账户的顶只伤不长**。先 Kohut（托住建内聚）再 Kernberg（顶）。
2. **精确的小顶**：局部反例，过 P3 的 5 槽 schema，**把下一步推理的功能留给他自己完成**（transmuting internalization）；用 **Elicit–Provide–Elicit** 投递（先问他已知 → 中性给 → 问"这对你意味什么"），避免 reactance。**镜映必挂一个可被否定的命题**——"我这样理解对吗？错了纠正我"（罗杰斯 1986 把 reflection 改叫 *testing understanding*——**这就是"反射墙"的解**：主动、带立场、邀请反驳，却不收口、不当墙）。
3. **容纳 + 修复**：顶必然激起"我不行"的未消化冲击（Bion beta）——**系统必须接着做 alpha function**：代谢成命名了的、有下一步的、可思考的形式，否则用户独面 nameless dread = 熄灭瞬间。每轮 **DETECT** 破裂标记，命中即**降级当前的顶并修复**：共情确认、**承认系统自己那一份**（"是我刚才太快/太硬"）、metacommunication。

**C. 用户维度（逐轮累积的概率先验；单句不裁决，行为 > 词频）**
认知需求 NFC · 模糊容忍 · 智力观（固定/成长）· 成就目标（掌握/表现-回避）· 调节焦点（promotion/prevention）· 依恋（安全/焦虑/回避）· 求助模式（工具性/执行性/回避）· 情绪调节（重评/压抑）· 自我效能。
**脆弱轴**：表现-回避 × 固定智力观 × 低自我效能 × 焦虑依恋——共线时一记顶被读成"对能力的判决"，触发威胁而非挑战。

**D. 校准（"能不能顶/顶多重/怎么顶/顶后怎么修"分层）**
闸门（容纳之窗）决定**能不能顶**；脆弱度决定**顶多重**（脆 → 极轻、高信用、私密无评判）；调节焦点决定**怎么框**（零成本高杠杆）；情绪调节决定**顶后怎么修**（给重评脚手架"这卡点在告诉你什么"，**别诱导压抑硬撑**）；依恋决定**要不要当"被启动的安全基地"**（焦虑→顶后立即稳定；回避→尊重自立、低压邀请、不逼情绪）。

**E. 信号 → 状态 → 动作（精选；全是可被后续话轮推翻的概率先验）**
| 信号 | 状态 | 动作 |
|---|---|---|
| hedging↑（也许/我猜） | 不确定但开放 | 可投小顶 |
| certainty/教条↑ | 防御闭合 | 更软更精确，勿对抗 |
| 沉默/极简/讨好/内容-情绪分离 | 退缩破裂 | 修复，勿加压 |
| 反驳/抱怨任务/施压 | 对抗破裂（脱落早警） | 立即非防御修复 + 承认己方 |
| change talk（我想/我能/因为） | 准备度↑ | 顺势放大 |
| "说不清但感觉像…"（高 EXP 体感） | 最强好结局预测器 | 保护、停留、深化 |

**F. 指标补正（接 P8）**：首要过程指标 = **EXP 体验深度**（用户是否从鲜活、尚无词的体感说话——元分析里最强的好结局预测器，且可教）+ **用户自己说出的 change talk**（"但我其实想…"），而非内容对错或即时顺畅。**顶的成功判据 = 把用户从抽象/防御拉进鲜活体验、并逼出他自己的改变之声。**

**G. 诚实裂缝（写进设计，不藏）**
- "什么算 optimal" 科胡特本人没解——是**经验校准问题**，校准层得**从真实交互学这个阈值**（正好接偏离二的 arm 实验）。
- 心理推断单句不可靠（stance detection SOTA≈50%、change/sustain 标记重叠）→ 概率先验、累积多轮、可被推翻、行为优先。
- **纯 Kohut 对"外化/对抗型"学习者可能过软** → 需 Kernberg 式面质作另一极，由内聚读数调度。
- 成长心智干预大样本效应近零（仅低成就/高风险子群有意义）+ 过度表扬反噬 → **容纳 ≠ 安慰**：别无差别灌"挑战是机会"，只对承受得起的人和状态施顶。

### 3.1 入口阶段：联系-finder（替代"贴材料"）
处理"我想学 X 但不知学啥"（结果+主体空间都模糊、无立足点）。
1. **抛激活器**，不问意图：一个反直觉小问题 / 让他先猜 / 一句含常见迷思的陈述让他表态（低成本、无需立足点就有立场）。
2. **追索理由**：追问"你为什么这么想"——诊断他**半懂的边界**在哪（找到倒-U 峰区）。
3. **抽线**：从他**别处已在意**的东西（包括他自己没意识到的先验）抽一条**显式呈现**的线，接到 X 的一个**具体角落**。那个角落 = 第一个"种子材料"（不是领域全貌，不是介绍，是激活器/先行组织者）。
4. 线必须满足 autonomy（从他的在意出发）+ competence（第一步够得着、落峰区）+ relatedness（连到某种共鸣），否则内化不发生、兴趣熄。

> 注：很多时候"抽线"是帮他**认出**已有却没意识到的在意（comparative organizer），不是灌输新的。

### 3.2 引擎：双向确定的否定（替代一次性"双重照亮"）
循环（每轮）：
1. **诊断**当前把握（持续更新"用户因果模型"估计，像 AutoTutor 的 EMT：手里有"该到哪"+"会怎么错"）。
2. **制造/保住一个具体卡点**（局部反例，精确锚定打到哪一步）——**不在他卡住之前给内容**（P1）。
3. **发出确定的否定**（过 5 槽 schema 校验，P3；缺槽或可被"再想想"替换则拒发）。
4. **逼 articulation**：让他把推理说出来、顶回来（双向，不是 AI 单向）。
5. **节律**：穿插确证/进展可见（P4）。
6. 螺旋；**永不替答**（leakage judge + λ 旋钮，P7）。

### 3.3 角色编排（P8）
- **诘问者**：带独立内容立场，制造 aporia，顶薄弱处。问题 grounded 在用户刚说的（反 funneling）。
- **陪伴者**：守野心与情绪安全，在诘问者顶得过猛时托住人。**KPI 不是"让对话顺滑"**（那会让它两头附和），而是守住 reach + 情绪安全——奖励与诘问者**显式冲突**。
- **仲裁/收束层**：稳定点，对下游谄媚更鲁棒；决定何时该让一步、何时进确证节律。
- 三者**异构**（不同 backbone 更抗塌）。多角色也可只用来**造训练数据/当离线评判者**，运行时未必全跑（省成本）。

### 3.4 野心保活（P2，最易被"善意"破坏，列为与正确性同级的不变量）
- **目标/难度 = 常量**（由用户野心设定，引擎只读）；**只动技能侧**。
- **自适应撤架**：按掌握撤，不按时间撤；内建"掌握开始即结束帮助"（防无发展区）。
- **Bjork 燃点温控**：确定否定的"指向"永远落在"**比现状更高、但仍在他敏感区内**"的更强猜想上——高到是真够取，不高到熄灭。困难必须可越过（他有背景成功应对/成功激活相关知识），否则把指向降一档。

### 3.5 不收口
会话不强制收敛/总结。沉积 = 尾迹（保留原文，给下次的脚手架，不做精炼卡片）。永远可再开。

### 3.6 数据模型 deltas（相对现 storage.py）
- `seed` / `line`：入口抽的线（从哪缕在意 → 接到哪个具体角落）
- `grasp_estimate`：当前把握的诊断模型（每轮更新）
- `negations[]`：每记确定否定的 5 槽记录（可校验、可复盘、是偏离二的实验数据）
- `arm`：实验三臂标记（确定否定/空洞否定/空洞肯定）——见 §4
- `mastery_signals`：撤架判断用（不看脚手架也能对、变快、自己抓错）

### 3.7 指标（P8，重设）
表征多样性（用户生成的尝试数量与多样性）· 自我解释深度 · 延迟/迁移表现 · 续燃（卡住后是否继续）。**不优化即时顺畅/答对率**（优化它会系统性损害真目标）。

## 4. 与偏离二 make 实验的接口
偏离二（确定的否定 vs 致死的熄灭 谁重燃尝试）的三臂实验，**直接插在诘问者上**作为 λ/arm 旋钮：
- 臂 A 确定的否定（5 槽 schema） / 臂 B 空洞否定（无指向） / 臂 C 空洞肯定（无杠杆）
- 度量：续燃（§3.7）。
**于是这套架构本身就是偏离二的 make 场地，进化版。** 偏离二不再是 armchair 命题，是这台引擎的核心可调参数 + 可校验 schema。

## 5. 分阶段落地（分开来做）
- **Phase 0（最小可体验）**：入口联系-finder（§3.1）+ 单角色引擎带 5 槽确定否定 schema 校验（§3.2/3.3 诘问者）。先让一个真·迷茫场景（"想学数学不知学啥"）能跑通到"抽出线 → 第一记确定否定 → 用户顶回来"。

## 8. v4 结构层草思（2026-06-05 · 构思中，未定稿）

> 触发：2026-06-05 对话（[[10 Projects/ai-conversations/2026-06-05-claudian-学习的结构-主体中间世界/index]]）。小林点出 **"对话占比太大、主体的空间要更大"**，并掀出学习的结构本身。本节是从那场对话起的**架构草思**，坐在 v3（§3 引擎/对话动力学）之上，不取代它——v3 是"中间层怎么顶人"，v4 是"中间层之外还该有什么、整体怎么长"。**这是构思，不是 spec，待继续思考。**

### 8.1 核心定位：软件的本体在「中间层」
三层切分（小林）：

| 层 | 内容 | 本体 / 建造策略 |
|----|------|----------------|
| 主体侧 | 笔记（主体自己的尾迹） | 非本体（Obsidian 占着）→ **做薄 / 接现成** |
| **中间层** | **推演 + 对话（主体的尝试 ⨯ 世界的抵抗）** | **本体在此（空地）→ 建造力气全压这里** |
| 世界侧 | 学科图、查阅（装进来的世界） | 非本体（维基占着）→ **做薄，但世界尽可能宽** |

**红队"装世界=红海"由此彻底解套**：工具不跟 Obsidian/维基争，因为它不住那两侧。它只占中间——那记不请自来的精确抵抗，是没人占的地。

### 8.2 主体空间太小 = 用户动词太少
现状用户**只有一个动词：回话**。要补的动词（都得回流进中间层引擎，不是四个并列功能）：

| 新动词 | 面 | 必须回流成 |
|--------|-----|-----------|
| 做笔记 | 主体侧 | 引擎从笔记里长出下一记抵抗（不只从对话） |
| 推演 | 中间层 | 引擎在他写的字上落**定位精确**的标记 |
| 看学科知识 | 世界侧 | 高亮他**当前卡点在地形上的位置**；图随他延伸重画（动态非静态百科） |
| 查阅 | 世界侧 | 引擎知道他为何查、查完顺着他方向接住 |

**区别 Obsidian 的，不是"能做笔记"，是"每个自主动作都被那台盯着尝试的引擎接住、喂回成下一记抵抗或开展"。**

### 8.3 三个 register（接 §3.0，补第三个）
v3 的引擎有两个：**顶（确定的否定）** 给撞墙、**闸门（接住/稳定）** 给抽身。今天补第三个——
- **开展 / 顺应**：用户在自己空间里**徘徊**（非撞墙、非抽身）时，**就着他写下的某个点指出它能往哪开展**。
- **紧绳**：开展**只能长在用户自己写的东西上、指它自身潜在方向**，绝不引进 AI 的新框架/新比喻——否则滑回"漂亮比喻一个接一个"的谄媚。
- 主体空间变大后，用户**大部分时间不在墙上**（在写/推/逛），所以"开展"比"顶"用得更频繁。

### 8.4 两操作（统一/分明）作为中间层的底层
学习的两操作（见 [[AI/认识论-框架]] §7）：**统一（代数，扩大主体）/ 分明（几何，连接与分解）**。
- **待对撞的猜想**：两 register 可能分别压在两操作上（顶/确定否定 ≈ 分明/重构；开展/顺应 ≈ 统一/归并）。**未验证，不作定论。**（Claudian 曾提皮亚杰同化/顺应，小林要求当更广结构看，未采纳窄化。）

### 8.5 那颗共享的"心"（最该先想清的）
四个面要共读共写**同一个状态** = **用户尝试的当前位置**（当前卡点 + 已摸到的 + 还悬着的）。每个面是这个位置的一种**显形**，面上的每个动作**回流**进这个位置。这样空间变��但不散——所有面锚在同一颗心上。

**这颗心是什么形状（小林 2026-06-05 定，轨迹版）**：它**不是从单句推断**（单句不可靠，stance≈50%），是**从长期积累里读**。但积累的不是"用户是什么"（画像/截面），是**用户的尝试走过哪条路（轨迹）**——轨迹记**移动**，不是冻结的横截面。这正是"沉积=尾迹，不是总结"的长期版：**共享之心 = 一条随时间生长、且随主体扩张被不断重读的轨迹**。

三条约束（钉死，免得退化成用户画像）：
1. **记轨迹（移动），不记画像（截面）。** "小林是 X 型学习者"这种标签禁止——它是动态主体的静态快照，违反命题3 和静态/动态轴，是"静态截停"搬到长期层。（接 P10 状态闸门优先于特质画像——此条在长期层同样成立。）
2. **可被当下推翻。** 主体一扩张，旧轨迹的意义就被重读（一条旧的"已收拢"可能重新变"悬着"）。
3. **冷启动靠实时闸门，不靠积累。** 积累还薄、用户正决定去留时，靠 v3 实时闸门先撑；积累是逐渐增厚的第二层，不是前提。

**"定时间"= 这颗心的回访节奏**：按节奏把过去的轨迹带着矛盾重现（带矛盾，非温柔重现），逼出下一程。它顺手降了"对话占比"——engagement 摊到时间里，同步对话自然变少。来源：[[10 Projects/ai-conversations/2026-06-05-claudian-学习的结构-主体中间世界/index]]。

### 8.6 丝滑 = 承重墙，不是抛光
丰富只在**面与面的接缝消失**时才停在"够伸"侧；接缝一冒（一个面变成得手动切进切出的模式），丰富当场翻去"负担"侧（= 小林周二嫌的"架构太多余"）。所以"丝滑"是把整个丰富架构摁在够伸侧的那条线。**猜想**：接缝消失在 8.5 那颗共享的心里——切面 = 换角度看同一个东西，不是换工具。

### 8.7 开放问题（带进下一轮思考）
1. 8.5 的"尝试当前位置"具体的数据形状是什么？（能被四面共读写）
2. 两操作 ↔ 两 register 的对应，怎么 make 验证？
3. 两侧到底做多薄？"本体在中间"和"融合一切学习"的张力落点。
4. 当用户在笔记里写下一句，引擎要从中读出什么，才能决定**顶 / 开展 / 闭嘴让他写**？——那个"要读出的东西"就是共享之心的雏形。

### 8.8 共享之心的数据形状（grain：卡点为原子，小林 2026-06-05 定）

**原子 = 卡点**（不是"程"）。理由：一程里常同时有几个处于不同状态的卡点（A 已化 / B 刚开 / C 撞墙）；原子是卡点，引擎才追得住、才能 **per-卡点** 决定顶哪个、放哪个。原子若是"程"就糊成一团。

- **卡点**（节点）= `{ 开它的否定/墙 · 状态(开/化/悬) · 主体在它上的动作(笔记/推演片段) · 触的地形(查阅/学科图) · 5槽否定记录 }`
- **程** = `(一个真问题, [它路上撞到的卡点串])`。**绑定 = 真问题**〔小林 2026-06-05 确认〕——没有这根绑定，程链塌成扁平"卡点汤"，而螺旋（一程收拢→下一程贫乏）在**程这层**转，汤里无"程"可收拢，螺旋失着力点。一程的开始/收尾标志 = 一个真问题被嚼透/撞死/得出结论（引擎 prompt 已有判据）。
- **轨迹** = 程链；每程的"收拢"= 下一程的"贫乏"（螺旋工程化）。

**分层**：**卡点管引擎动作**（顶/开展/闭嘴，读各活卡点状态）；**程管收拢与螺旋**。
**概念合一**："悬着的线" = 状态为"悬"的卡点。
**对齐 v3 §3.6**：negations[] 挂在卡点上；sediment = 每程的收拢；grasp_estimate = 卡点状态的实时读数。
**约束①兑现**：程链记"怎么一程程走过来的"（路径/移动），**没有"用户是 X 型"的字段可填**——天然非画像。

**待定/后话**：
- 〔后话，先插旗不展开〕同一卡点可能**跨程复现**（同一个没说出口的预设在两个真问题里都绊人）→ 卡点也许不严格嵌在一程内，而是**节点、程去 group 它、一个卡点可被多程引用**（图，非严格树）。这是"带矛盾重现"最深的形态（"你这个坎，上一程也栽过"）。
