# 对话标注

> 把一坨 AI 对话原文，变成**未来的 AI 读了不会误会**的归档。
> 核心不是排版好看，是让读者一眼分清：哪句**承重**、哪句还在**试**、哪句是小林**顶回**了 AI。

raw 原文里藏着三种"读起来困难"，要分开治：

| 层 | 病 | 谁能治 | 不治的后果 |
|----|----|------|----------|
| ① 清洗 | 导出工具灌进正文的噪声（思考摘要、UI 残渣、串行时间戳、一段到底） | 机械/脚本式 | AI 把"Codex 泄露的内心戏"当成真对话——**最常见的误会源** |
| ② 结构 | 没有说话人、没有回合边界 | 轻读一遍 | "谁说的"张冠李戴 |
| ③ 认知 | 看不出实在/幻觉/校正/废案 | 带着认识论读 | 把探索当结论——**最深的误会** |

---

## 三层模型（本技能的产物）

一个会话目录下**三个文件，各司其职**：

```
10 Projects/ai-conversations/<日期>-<来源>-<主题>/
  raw.md      ← 原文，一字不改。第一手档案，神圣不动（哪怕带噪声）
  标注.md     ← 本技能的核心产物：清洗 + 说话人 + 认知标记
  index.md    ← 给下次 AI 的尾迹（摘要层，已有约定，不在本技能范围）
```

- **raw 为什么神圣**：按认识论"沉积=保留原文，不是总结"。raw 是事实，连导出噪声也是事实的一部分。**清洗发生在 标注.md，绝不回写 raw。**
- **标注 为什么独立成层**：index 是摘要，丢了纹理——看不见校正发生在流里的**哪一点**。标注层保留逐回合的流，同时把认知状态贴上去。读 raw 时有标记，这是 index 给不了的。
- **三个都要，不是二选一**。日常进相关话题先读 index；要复核细节读 标注；要逐字原文翻 raw。

## 流程

1. **判来源**（决定清洗力度）：看 raw 是**网页导出**还是**终端导出**（特征见下）。来源不同，噪声完全不同。
2. **读 raw**（长会话用 subagent 深读，别占主上下文）。
3. **写 标注.md**：
   - 顶部 frontmatter（见模板）。
   - 逐回合：标说话人 → 清洗噪声（清掉的在行尾用 `（清:…）` 留一句说明，**不静默删**）→ 在承重句上打认知标记。
   - 末尾留 `## 标注者备注`：列出本次发现的 `〔校正〕`/`〔开口〕`/`〔割裂〕` 清单 + 任何 `〔?〕` 存疑点，给人复核。
4. **给 raw 补轻量 frontmatter**（若缺）——只动 frontmatter，**不碰正文**。
5. **不动 index.md**（那是另一套约定）。报告里提示"index 可据 标注 校一遍"。

## 来源分叉：清洗规则

### A. 网页导出（Codex.ai / ChatGPT 网页 / Gemini 网页）—— 噪声最重

网页导出会把 **UI 元素灌进正文**，这些看起来像内容，其实是残渣，**必删**：

| 噪声 | 实例 | 处理 |
|------|------|------|
| AI 思考摘要（斜体小字被导出） | `识别了高杠杆交易费用问题并准备回应。`（常**连续重复两遍**） | 删。识别特征：出现在 AI 回合**之前**、"识别了…/权衡了…/评估了…/探索了…"句式、紧跟时间戳、常重复 |
| 工具/状态 chrome | `Searched the web` `Thought for 1s` `Show more` `Fetched: GitHub - …` `Pivoted to…` | 删 |
| 串行时间戳 | `03:11` 卡在句子中间 | **不删**，提到回合开头标 `〔t=03:11〕`（时间戳是有用的——能看出对话的弧线/深夜到清晨） |
| 一段到底 | 整篇无换行 | 按回合拆段，回合间空行 |
| 包裹符 | `++[文字](url)++` 的 `++` | 还原成普通链接 |

> 思考摘要要不要全删？默认删（它是 AI 没说出口的内部状态，不是对话）。若某条**确实泄露了有价值的推理转折**，可保留为 `〔思:…〕` 单独一行，但默认删。

### B. 终端导出（opencode / Codex / Claudian）—— 已经较干净

| 特征 | 处理 |
|------|------|
| 已有 frontmatter、回合用空行分隔 | 保留 |
| 斜杠命令 `/model` `/cost` `/clear` | 保留，但标 `〔cmd〕`（它们是真实操作痕迹，不是对话内容） |
| 编码乱码 `���` | 标 `〔乱码〕` 占位，**不猜**原文 |
| 主要缺的是说话人 + 认知标记 | 这是终端导出的主战场 |

### 通用铁律

- **只删导出工具注入的非对话残渣，绝不删任何一句真对话。**
- 拿不准是不是噪声 → **保留**，标 `〔?〕`，写进备注让人定。
- 清洗有损时（删了东西）→ 行尾 `（清:删了重复两遍的思考摘要）`，留痕，不静默。

## 认知标记词表（③ 层，本技能的灵魂）

标记用**全角方括号** `〔〕`，直接贴在转录流里。这套词表就是 vault 的认识论贴到对话上——含义以 [[AI/认识论-核心]] / [[AI/认识论-框架]] 为准。

**说话人（必标，每回合开头）**
- `〔林〕` 小林　/　`〔AI〕` AI（可注明模型：`〔AI:sonnet〕`、`〔AI:claudian〕`）

**认知状态（标在承重句上，不是每句都标）**

| 标记 | 含义 | 怎么认 | 挡住的误会 |
|------|------|--------|----------|
| `〔实〕` | 已确认、承重、小林背书的判断 | 语气在**收束/确认**；"对""是的""就是" | 把承重当随口 |
| `〔幻〕` | 探索中、还没实在化的可能 | 语气在**假定/试探**；"可能""似乎""我在想" | 把探索当结论 |
| `〔校正〕` | 小林**顶回** AI 的方向 | 小林反驳/纠偏 AI 上一回合——**原话保留，最高价值** | 漏掉转折点 |
| `〔弃〕` | 试过被明确放下的路 | "算了""不是这个""先不" | 把废案当活案 |
| `〔开口〕` | 悬而未决、可下次接的入口 | 抛出没收尾、AI 没接的问题 | 当成已闭合 |
| `〔割裂〕` | 主体在此移位，问题本身变了 | 话题中心整个换了，回不去原坐标 | 把新主体拉回旧坐标 |
| `〔?〕` | 标注者拿不准 | — | 留给人复核 |

**标注原则（防过度标注）**
- 一个回合 **0–2 个**标记。满屏标记 = 新噪声。
- `〔校正〕` **必标，且原话一字不改**——这是整套技能防误会的核心，比任何排版都重要。
- `〔实〕`/`〔幻〕` 的分界看**小林有没有背书**，不是看"听起来对不对"。
- 真拿不准 → `〔?〕`，不硬标。宁缺毋滥标错。

## 标注.md 模板

```markdown
---
type: annotated-conversation
date: <日期>
participants: 小林, <AI名/模型>
source: <web|terminal> 导出
raw: "[[raw]]"
annotated_by: claudian
标记图例: 〔林〕〔AI〕说话人 · 〔实〕承重 · 〔幻〕探索 · 〔校正〕顶回(原话) · 〔弃〕废案 · 〔开口〕悬置 · 〔割裂〕主体移位 · 〔?〕存疑
---

# 标注：<一句话主题>

> 来源：<web/terminal>。清洗痕迹见行尾 `（清:…）`。认知标记词表见 frontmatter 图例 / [[.Codex/skills/对话标注/SKILL]]。

<逐回合的清洗+标注正文>

## 标注者备注（给人复核）
- **校正点**：<逐条列，带原话引用>
- **开口**：<悬置的入口>
- **割裂**：<主体移位处，若有>
- **存疑 〔?〕**：<拿不准的清洗/标记，让小林定>
```

## 紧凑范例（before → after，兼作 exemplar）

**before（6.6 网页导出原文，一坨）：**

```
确实，止损很少加 03:33 权衡了风险提示与实用建议的平衡。 权衡了风险提示与实用建议的平衡。 这个习惯挺危险的，尤其配了高杠杆。…… 听起来像是数学问题。 06:40 你的思路是错误的。尝试不能是这样的。数学建立在以形式化正确严谨闭环为基础。但是认知？真的完全是这样吗？……数学无法包揽关于他的一切。……而这种可能性就是幻觉。
```

**after（标注.md 正文）：**

```markdown
〔林〕确实，止损很少加。　〔t=03:33〕

〔AI:sonnet〕这个习惯挺危险的，尤其配了高杠杆。……
（清:删了重复两遍的思考摘要"权衡了风险提示与实用建议的平衡"）

⋯⋯

〔AI:sonnet〕……（建议把直觉翻译成最小数学形式）　〔t=06:40〕

〔林〕〔校正〕〔割裂〕"你的思路是错误的。尝试不能是这样的。数学建立在以形式化正确严谨闭环为基础。但是认知？真的完全是这样吗？……数学无法包揽关于他的一切。"
　← 顶回 AI"把直觉翻译成数学形式"；对话中心从"工程怎么落地"整个移到"认知/存在/尝试"——此处主体移位

〔林〕〔实〕可能性就是幻觉；存在于自由与束缚之中；自由与束缚就是空间；没有空间就剩空无；空间靠尝试定义。
```

**注意 after 里发生了什么：**
- 串行时间戳 `03:33`/`06:40` → 提到回合开头 `〔t=…〕`。
- 重复两遍的思考摘要 → 清掉，行尾留痕。
- 小林那句长反驳 → `〔校正〕` 原话保留 + 标了 `〔割裂〕`（这里对话主体真的移位了）。
- 小林收束的本体判断 → `〔实〕`。
- 一坨 → 按回合拆开。
