# Obsidian 外脑工作流

## 核心判断
接入 Obsidian 的意义，不只是多一个命令，而是把对话、思考、项目推进真正落进可持续的个人知识系统。

从“我会说”，变成“我会说，而且能直接写进你的系统里”。

## 这套系统能做什么
### 1. 直接操作笔记库
- 读取某篇笔记
- 搜索整个库
- 新建笔记
- 追加内容
- 维护 daily note

### 2. 把会话沉淀成长期知识
可沉淀为：
- 项目页
- 长期主题页
- 学习路线
- 概念卡片
- 决策记录
- 每日记录 / 周回顾

### 3. 做半自动知识管理
典型工作流：
- 聊完一个话题 → 自动归档
- 项目推进完一段 → 生成项目纪要
- 灵感出现 → 直接进 Inbox
- 回顾一段时间在忙什么 → 结合 daily notes 总结

## 对当前使用方式最值钱的三类能力
### A. 长期主线管理
适合数学 / 哲学 / 创作 / 项目推进等长期问题，持续维护：
- 当前进度
- 卡点
- 下一步
- 关联材料
- 阶段总结

### B. 对话沉淀
把高价值对话整理成：
- 结论版
- 洞察版
- 可执行版

### C. 个人知识库活化
不是死笔记，而是可搜索、可追踪、可更新的系统。
