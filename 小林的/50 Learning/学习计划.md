最小执行方案？（可行性存疑）

- 每学完一段内容，立刻合上资料用 5 分钟写“我能回忆出什么？”
- 第二天/第4天/第10天各做一次短测（自己出题或让 AI 出题）
- 用“错题本”驱动复习，而不是按章节重读
  
  
  ###  Phase 1：爆发期（Burst Phase）—— 尽情释放你的天性

| 要素       | 操作                                            |
| -------- | --------------------------------------------- |
| **时长**   | 1~7天的高强度沉浸                                    |
| **目标**   | 快速建立"全景认知地图" —— 不求精通每个细节，求的是**知道整个领域长什么样**    |
| **方法**   | 大量输入（读/看/听/做），允许粗糙理解                          |
| **关键纪律** | 每学习60~~90分钟，**必须休息10~~15分钟做完全无关的事**（走路、运动、发呆） |


#### 方案B：长期目标（永久性知识）

[8](https://training.safetyculture.com/blog/how-spaced-repetition-works/) 推荐的最佳间隔重复间隔为：第1次复习：初始学习后1天；第2次复习：初始学习后7天；第3次复习：初始学习后16天；第4次复习：初始学习后35天。

text

```
爆发日 → 第1天 → 第7天 → 第16天 → 第35天 → 第90天
```

[8](https://training.safetyculture.com/blog/how-spaced-repetition-works/) 但最佳间隔时间因人而异。对于容易回忆的信息，可以使用更宽的间隔；对于更难记忆的内容，可以缩短间隔。
