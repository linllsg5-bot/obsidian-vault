# Hi Robot：分层 VLA 让机器人"先思考再行动"

> Physical Intelligence 2025-02 发布的论文（arXiv:2502.19417）。在 π0 之上叠加一个高层推理 VLM，形成 System 2（慢思考）+ System 1（快反应）的分层架构。让机器人能处理复杂多步指令、实时反馈、修正错误——比直接用 π0 大幅提升复杂任务的成功率。

> **⚠️ 内容基于 WebSearch 综合**，关键引用为概括性转述（非论文原文逐字），等拿到原文 PDF 可以替换 stub 后重新整理。

## 核心论点

- **分层架构 = System 2 + System 1**：高层是预训练 VLM（跟 π0 同骨架），输出文字（"先拿全麦面包片"）和元命令；低层是 π0 VLA，把元命令转成 50Hz 的电机指令。**两层异步运行**，高层不需要每帧都跑。

- **核心问题：flat VLA 处不了复杂指令**：直接的 VLA 模型能完成"拿杯子"这种简单命令，但对"清理桌子，记得别把那个红色玩具扔了"这种带约束/反馈的复杂指令束手无策。Hi Robot 用语言推理作为缓冲层。

- **训练方法的关键创新：合成数据**：用先进 VLM 基于机器人视觉上下文**自动生成可能的用户指令**，作为高层策略的训练数据。这绕过了"复杂指令的标注数据极难收集"的瓶颈。

- **类比 LLM 的 chain-of-thought**：就像 LLM 在 thinking tokens 里展开推理能提升复杂题目准确率，Hi Robot 让机器人用语言把任务**分解成它已掌握的简单步骤**再执行。

- **超过 GPT-4o**：在指令跟随准确度上比 GPT-4o 高 40%。这点意外——GPT-4o 这种通用 VLM 直接做规划，反而不如专门为机器人微调的 Hi Robot 准。

- **跟 π0 是垂直整合关系**：Hi Robot 没有取代 π0，而是把 π0 当作低层"肌肉记忆"。π0 的灵巧动作能力 + Hi Robot 的推理能力 = 完整能力栈。

## 关键观点（WebSearch 综合，非原文逐字）

- 设计哲学："give robots an inner voice similar to what humans hear when solving difficult problems"——让机器人有类似人类解题时的"内心独白"，把推理过程显式化。

- 实验任务覆盖：清杂乱桌面、做三明治、超市采购。**特意挑能用语言反馈纠正的场景**（"那个不是垃圾"），测分层架构的真正价值。

- 评估机器人：单臂、双臂、双臂移动平台。说明分层架构跨形态可迁移。

## 跟 π0 系列的位置

```
π0 (2024-10)          ← 通用机器人基础模型（低层 VLA）
└── Hi Robot (2025-02) ← 在 π0 之上加分层推理（独立的高层 VLM）
    └── π0.5 (2025-04) ← 把 Hi Robot 的分层思想内化到单模型，加异构数据 co-training
```

**Hi Robot 跟 π0.5 是技术上的延续关系**：Hi Robot 用两个独立模型做分层；[[80 知识库/具身智能/素材/π0.5-Open-World泛化-2026-05]] 沿用了"先输出文字推理再输出动作"的思路，但合并到一个模型里。

详见 [[80 知识库/具身智能/_主题页]]。

## 后续影响

这个 System 1/2 分层 VLA 思路被多个后续工作沿用：
- DP-VLA（Dual Process VLA）
- Fast-in-Slow (FiS-VLA)
- NVIDIA GR00T N1 / Cosmos Reason
- VINE

可以认为 Hi Robot 开启了 "dual-system VLA" 这条研究路线。
