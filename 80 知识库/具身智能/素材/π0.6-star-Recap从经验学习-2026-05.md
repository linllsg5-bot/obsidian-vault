# π*0.6：Recap——让 VLA 从自己的实践经验中学习

> Physical Intelligence 2025-11 发布。基于 π0.6（π0.5 的 5B 精炼版），用 **Recap（RL with Experience & Corrections via Advantage-conditioned Policies）** 三阶段训练：示范 + 纠错 + 自主经验。结果：在工厂装盒子、做意式咖啡、叠 50 种衣物上，吞吐量翻倍、失败率减半，能 5:30am-11:30pm 连续作业一整天。**这是 π 系列第一次质变：从 supervised learning 到从经验学习。**

## 核心论点

- **学习类比是论文的灵魂**：人学装盒子 = 看示范 + 被纠正 + 自己练。当前 VLA 大多只用第一步（imitation learning），所以"成功一半容易，每次都成功难"。要达到实用级稳定性必须三步全用。

- **模仿学习的根本问题：compounding errors**：模型小错误会让机器人进入训练数据没覆盖的状态，从而犯更大错误，雪球越滚越大。LLM 没这个问题（静态输出），但 VLA 是控制策略——跟环境持续交互，这是 VLA 独有的痛点。

- **Recap = 三阶段训练管线**：
  1. **Offline RL pretrain**：取代标准的 supervised 预训练
  2. **Demonstrations 微调**：教新任务的基础
  3. **Corrections + Autonomous RL**：专家在 robot 犯错时接管 teleop 提供纠正；机器人自主练习用 value function 做信用分配

- **核心技术：Advantage-conditioned policy**：把 value function 的变化（advantage）作为 VLA 的**条件输入**——告诉模型"这个动作是好是坏"。训练时所有数据都用（不管好坏），推理时只让模型生成"高 advantage 动作"。这样既保留了数据多样性又能筛选好行为。

- **解决了 RL 的关键瓶颈：credit assignment**：portafilter 插不进去的真正错误是更早的"抓握角度不对"。用 value function 识别"哪些动作让局势变好/变差"，从结果反推过程。

- **结果是实用级 throughput**：
  - 装盒子：59 个工厂级巧克力包装盒，无中断
  - 意式咖啡：5:30am - 11:30pm 一整天连续做各种饮品
  - 叠衣服：50 种新衣物、新家、小时级无中断
  - 整体成功率 >90%，throughput 翻倍

## 关键技术细节

- **基础模型**：π0.6 = π0.5 精炼版，5B VLM + action expert，支持异构 prompt（包括 desired execution quality、desired advantage）
- **三阶段训练**：
  1. Offline RL pretrain（替代 supervised pretrain）
  2. Task-specific SFT（demonstrations 微调）
  3. On-robot RL：corrections + autonomous experience，advantage-conditioned policy extraction
- **Value function**：预测从当前状态到完成任务的（负）步数。值越接近 1.0 = 离成功越近
- **Advantage 用法**：训练时作为额外的条件信号；推理时直接告诉模型"输出高 advantage 动作"
- **跟 π0.5 一致**：espresso 长任务还是用 **high-level language policy**（继承 π0.5 的分层方法）

## 性能跃迁

四个训练阶段的 throughput（次/小时）：

| 任务 | π0.6 (SFT) | π*0.6 Offline RL | π*0.6 + SFT | **π*0.6 final** |
|------|-----------|------------------|-------------|-----------------|
| 装盒子 | ~6 | ~10 | ~12 | **~15** |
| 叠衣服 | ~30 | ~45 | ~55 | **~65** |
| 意式咖啡 | ~10 | ~20 | ~25 | **~32** |

最难的意式咖啡，throughput 和成功率都翻倍。

## 论文的更大野心

未来的数据格局可能不再是"采集示范数据"，而是：
- **示范** = 定义新行为
- **纠错** = 优化策略
- **自主经验** = 精进 → 可能达到**超人表现**

这跟 AlphaGo 从模仿人类棋谱到自我博弈的演化路线类比强烈。
