# π0.7：涌现的组合泛化——单一通用模型替代所有 specialist

> Physical Intelligence 2026-04 发布。π0.7 是 π 系列**最重要的质变**：第一次在 VLA 里看到 LLM 式的 **compositional generalization**——把训练里没见过的技能组合成新任务（用没见过的空气炸锅、把叠衣服动作迁移到没训练过的工业臂）。关键技术是**多样化的 multimodal prompt**——language + metadata + control modality + visual subgoal——让模型既能消化海量异构数据，又能在测试时被精确"调控"。

## 核心论点

- **VLA 第一次有 compositional generalization**：LLM 能组合"英译法 + JSON 输出"得到"英译法的 JSON"；之前的 VLA 不行。π0.7 在空气炸锅实验展示：训练数据里**只有 2 条关闭空气炸锅的数据 + 1 个 DROID 数据集 Franka 数据**，但模型能在新场景里完成"放红薯进空气炸锅"。

- **Steerable = prompt-conditioned 行为**：模型行为可被 prompt 精确"调控"。Prompt 不再只是 "do task X"，而是包括：
  - **Diverse language**：任务描述 + 子步骤
  - **Metadata**：speed、quality 等
  - **Control modality**：joint vs end-effector
  - **Visual subgoals**：世界模型生成的"理想下一帧"图像

- **Prompt diversity 解决数据问题**：suboptimal 的自主数据（之前会污染训练）现在可以用——只要打上 "lower quality" 标签。这让模型可以**安全消化海量异构数据**而不被坏数据带偏。

- **单模型 = 多 specialist**：π0.7 把 π*0.6 的多个 task-specific specialist 的能力蒸馏到单模型，**单模型的吞吐量和成功率达到甚至超过 specialist**——颠覆了"通用模型不如专才"的传统观念。

- **跨形态 zero-shot 转移成功**：训练数据只有"小型双手机器人叠衣服"，测试在"工业 bimanual UR5e"——完全不同形态、不同动力学。π0.7 的零样本成功率**等于专家 teleoperator（375 小时经验）第一次操作 UR5e 的成功率**。

- **Language coaching 是新的 fine-tuning**：空气炸锅 zero-shot 失败，但**用语言一步步教**就能成功。然后这些 coaching 反过来 fine-tune 高层 policy，让模型完全自主完成。这是一种新的"低门槛任务定制"——不用收集机器人数据，光用语言就能教。

> "we see π0.7 exhibiting the first signs of compositional generalization, recombining skills from various tasks to solve new problems"

## 三个关键实验

### 1. 空气炸锅（compositional generalization 经典案例）
- 数据集没有"用空气炸锅"演示
- Zero-shot prompt 失败
- Step-by-step language coaching → 完成
- 用 coaching 数据 fine-tune 高层 policy → 完全自主完成
- **追溯**：只找到 2 条关闭空气炸锅 + 1 条 Franka DROID 数据。模型从这点碎片组合出新行为

### 2. 跨形态叠衣服（cross-embodiment）
- 训练：小型双手机器人叠衣服
- 测试：bimanual UR5e（重型工业臂，不同形态/动力学，没有任何叠衣服数据）
- 结果：零样本成功率 = 375 小时专家零样本

### 3. 单模型替代 specialist
对比 π0.7（通用）vs π*0.6 specialist（每任务专门 RL 训）：
- 叠衣服（T-shirt/Short）：通用 ≥ 专才
- 叠衣服（diverse / 最难）：通用 ≥ 专才（甚至 1.6x throughput）
- 意式咖啡：通用 ≥ 专才
- 装盒子：通用 ≥ 专才（甚至 1.6x throughput）

## 关键技术细节

- **基础**：VLA 模型 + action expert
- **多源数据**：多种机器人 + 人类视频 + 各种 policy 跑出来的 autonomous episodes
- **训练时 prompt 组件**：
  - Language instructions（任务 + 子步骤）
  - Subgoal images（episode 各点的目标画面）
  - Episode metadata（quality、speed）
  - Observation memory（历史观察）
- **推理时**：
  - 高层 policy 输出 subtask instruction
  - World model 生成 subgoal images
  - 用户可指定 desired metadata（speed、quality）
  - Action expert 输出动作
- **关键创新**：autonomous data + 质量 metadata 标注 → **可以用"差数据"训"好模型"**

## 跟 π0 系列的位置

```
π0 (2024-10) → Hi Robot → π0.5 → π*0.6 (2025-11) → π0.7 (2026-04)
                                  task-specific      所有能力蒸馏到
                                  specialist         单一 steerable 模型
                                  (RL)               + 涌现组合泛化
```

π0.7 是这条线的**集大成**：吸收 π*0.6 的 RL 训练成果 + π0.5 的异构数据 + Hi Robot 的分层思路，全部用 steerable prompt 统一。

## 论文的更大野心

文末预言：未来可能让 π0.7 这样的模型自己 **"think through"** 复杂任务——基于多模态 prompt 落地思考、执行、反思、修订。这是把 LLM 的"semantic reasoning"转化为"physical reasoning"的路径。
